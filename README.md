# CocSWSkill · 剧本撰写与开发

把一个故事设想，逐步发展成**可读、可调查、可选择、可主持、可维护**的剧本。

CocSWSkill是一套中文剧本开发方法与可按需加载的Codex skill，面向《克苏鲁的呼唤》（COC）模组、互动游戏叙事及一般舞台／影视故事。可以直接阅读文档，也可以让AI助手按任务调用。使用无需运行脚本或安装Python。

## 项目背景

剧本开发常见的困难并不只是“写得不够多”：人物动机和线索功能混在一起，后台真相无法转成玩家亲手推理，地图施工早于因果设计，修改正文后主持材料仍沿旧版本。

本项目来自持续的COC开发实践、通用方法整理、研究转译和多轮独立AI审阅。它将分散经验组织为按媒介、目标与阶段使用的体系，保留来源和验证范围，让后续开发可以复用、定位问题并维护。

## 目标与适用范围

- **一般叙事剧本：**让人物行动、冲突、主题、结构与场景表达成立。
- **互动游戏剧本：**让选择改变条件和世界状态，并留下可感知的持续成果。
- **COC模组：**将故事、证据、调查与行动连成可主持的体验，配套场景、手证和KP材料。

你可以制作新稿、诊断已有方案、局部修订，或进行阶段审核。公开救援等非调查任务无需另造隐藏谜题；数字互动的文案／状态接口与引擎实现分别处理。

## 简要开发流程

**大纲形成 → 体验设计 → 逐线强化与融合 → 世界事实与痕迹 → 推理／事件章程 → 地图与场景 → 规则与KP工具 → 测试修订 → 成品交付**

先写玩家能够经历的完整代表路线，再落实因果、信息与运行。每阶段按“编制—审核—实改—复核”推进，后续设计可以按影响范围返回上游。关键规则与现实可行性及时核验。

## 方法特点与优势

这些特点是研究与实践经验的工程整合，不宣称学术首创，也不以AI审阅代替真人效果验证。

| 特点 | 解决什么问题 |
|---|---|
| 媒介、任务、阶段分别分类 | 一般叙事、互动和COC按需增加方法，局部任务无需加载整个体系 |
| 从剧情用途设计推理 | 将目标、竞争解释、证据组合、调查路径和行动用途连接起来 |
| 亲手推理与线索投放一起设计 | 不只决定在哪里放答案，还设计比较、验证、重估和提供机会 |
| 时间、体验与疲劳共同检查 | 分清现实时间、世界时间与个人参与，检查积累、释放和真实恢复 |
| 主题落实到场景与材料 | 用具体行为和呈现产生体验，保留中性对照及证据公平 |
| 真实选择与成果持续 | 提前识破、救援、取消和延迟实际生效，后续按新条件发展 |
| 单一归属与可追溯维护 | 定义按领域维护，来源、变更和同版本验收记录可查 |

评价使用百分制、允许小数，默认展示两位；细分须有依据。模型分数不能替代因果、公平、可行性或作品分维验收。

## 快速开始

```powershell
git clone https://github.com/28714026262/CocSWSkill.git
cd CocSWSkill
```

让助手读取`coc-script-writing/SKILL.md`，说明已有材料、固定事实、本轮任务与交付目标，例如：

```text
读取 coc-script-writing/SKILL.md，检查我的COC大纲。
先分析人物因果与玩家参与，保留已确认事实，交付诊断和优先修改项。
```

```text
基于现有世界事实，设计这个事件的推理目标、线索组合和投放条件。
说明玩家怎样亲手判断，以及提前识破、拒绝供述或材料损失后怎样继续。
```

```text
评估这份阶段剧情稿的游玩时间和节奏。
资料不足时先做轻量诊断，给出时间范围、证据缺口与优先修改建议。
```

想用`$coc-script-writing`直接调用，可按[个人安装说明](coc-script-writing/README.md#安装为个人技能)复制整个技能目录；直接读取文档无需安装。
