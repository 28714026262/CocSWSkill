## 1. 工作合同与覆盖盘点

先确认本轮对象、采用版本、可改事实、交付范围和验收承诺。既有作品从实际文件读取，不能只靠会话记忆；已有部署还需核对当前运行内容与源文件的对应。未读材料注明未读，后续发现矛盾再回查。

用户已有通用工作台且未指定其他载体时，依[接入合同](integration.md)交内容资源，不重开发工具；文件稿按本轮载体验证正文、必要资源、独立分发与同版，不追加服务门槛。本轮只定义规范时，不因此执行真实导入、部署或更新场次；选择工作台交付时，完成测试空间接入才可宣称该接入可用；文件成品按其承诺单独验收。

建立覆盖表：原稿条目→当前采用事实→P8 章节／实体→地图／线索／材料→文件→验证证据。盘点人物、地点、场景、事件线、机制、线索、资料和资产，逐项标明已覆盖、合并引用、不适用、待补或存在冲突。实际数量从清单生成，不把上一项目的人数、房间数和素材数带过来。

同名与同 ID 不自动合并：先核命名空间、实体和版本关系。不要将“提到名字”算作完整覆盖：一个地点必须有可主持内容，一条线索必须有可取得的实际信息，一件手卡必须有可打开文件。

<a id="src-p8-production-qa-16"></a>
## 2. 先补内容，再统一编排

先区分设计缺口与制作缺项：事实、证明、规则、门路或关键因果缺失回责任阶段；采用事实已经完整，只缺可读文字、载体原文的呈现、索引或渲染时由P8按既有授权制作。先修阻断理解和运行的缺项：历史因果、玩家接入、知情范围、证据内容、全地点设定、规则数据、结局与状态传递。修订关键事实时列出上游变更方案和受影响产物，按项目授权及约定审核；已允许的普通补写可继续，不因流程名义反复申请许可。

结构确认后编写完整正文。线索、人物、地图和场景共用实体及引用，生成不同视图；旧资产可复用，旧页面依赖需解除。检查同一事实在文字、表格、几何、图像和手卡里是否冲突。

<a id="src-p8-production-qa-22"></a>
## 3. 小样、扩展与输出

先从本轮适用对象中选代表性内容验证版式和画风：长文、表格、时间轴、密集人物、最小房间和一个完整玩家材料。地图有实际参考图时进行对照；没有则按声明标准审小样，不虚构对照。通过后扩展全量。

完成内容和必要资产后，按制作合同统一生成所选的完整阅读、PDF、速查、图册、玩家材料和打包入口；未选择的载体无需补做。不要每处小改都全量重渲染大部头，先检查改动对象，收敛后重建受影响成果。最终同版、同源必须核验。

## 4—5. 执行审读与验证

角色化审读和验证矩阵的完整协议唯一在[production-verification第4节](../../../scenario-review/references/production-verification.md#src-p8-production-qa-28)及[第5节](../../../scenario-review/references/production-verification.md#src-p8-production-qa-44)。制作方在输出候选后按承诺调用，向审核者提供真实同版文件和必要采用源；作者执行这些视角时如实记自审，项目要求独立席时按真实身份安排。

制作方必须接回并形成：当前对象／版本与实际覆盖，具体位置及影响的问题表，真实修订文件和受影响视图同步，原审核者复读的关闭依据，未完成承诺／未测范围及资格说明。领域判据分别执行空间／媒体／规则等实际检查，review协议不能代做图面、听审或规则核查。按本轮载体完成适用矩阵；缺必要资源、正文、独立验收或运行证据时保持该项未完成。没有新改动或残余问题不为轮数重复签通过。

<a id="src-p8-production-qa-58"></a>
## 6. 已有本地服务的更新边界

只在用户授权更新当前服务时执行，不因提炼规范而修改运行环境。确认实际容器、端口、剧本及文件位置，不能只依据旧会话中的地址。

发布前备份完整正文、媒体和场次；真实场次读取完整状态，而不是只保存列表摘要。用临时场次验证，保留并比较真实记录、版本和时间。更新前核当前内容指纹，若已被其他工作修改，重新合并判断，避免覆盖用户编辑。

候选、作者源、示例包、运行内容和下载文件一致后才完成发布。采用本地文件和对象存储备份时，实际上传、取回并比较校验和；记录备份存在不等于验证可恢复。恢复优先新建空间，不覆盖原业务数据。此流程按实际服务能力实施，不额外引入生产平台模块。

<a id="src-p8-production-qa-66"></a>
## 7. 完成判定与说明

仅对制作合同内的适用对象判定：完整正文已编排；覆盖缺项有明确结果；地图、线索和机制可用；玩家包独立且不泄密；资产可显示／播放；所选打印和 HTML 同版；必要操作与迁移通过；阻断问题关闭。未承诺的工具、PDF、媒体类型和服务验证标为不适用，不判作漏交；未完成的承诺也不能通过换成“参考建议”消失。

最终说明给出入口、完整包、版本、测试环境、实际执行和必要限制。未逐页视觉审查、未真人桌测、未测浏览器等如实写，不泛化为无关免责声明。证据位置与当前对象对应即可，不需要把所有生产日志堆进剧本正文。
