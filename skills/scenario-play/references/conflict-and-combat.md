# 冲突与战斗的目的、策略及后果

<a id="src-coc-31"></a>
## 战斗目的、执行条件与规则接口

通用方法处理冲突为何发生、各方想改变什么、可用策略和真实后果；伤势、SAN及其他系统数据只在采用相应规则时读取适配。规则系统、是否战斗、恐怖题材和当前开发阶段分别确认。没有战斗的作品可据体验和实际行动范围说明本项不适用，不为填完整性强造战斗。

<a id="src-coc-34"></a>

先按参与人数与实际分工检查冲突现场：谁正暴露、谁保护或操作、谁能联络与撤离，空间是否容许这些动作。多人分线不自动共享情报；单人不能同时承担互斥岗位。注意力与轮候原则见[互动](interactive.md#src-coc-33)，具体轮次按系统配置。

<a id="src-coc-36"></a>

## 1. 从目标推策略

战斗围绕真实目标组织，例如护送、争取退路、阻止破坏，或保住结构、工具和证据。按目标结算结果，不以每次清空敌人HP作为唯一完成条件。

逐方写当前目标、已知局势、可用能力／资源及停止条件。冲突可以是争夺同一资源、阻止一项行动或保护不同对象；谈判、欺骗、威慑是否可能，取决于该方目标和认知，不保证所有敌方均可说服。对方按[人物模型](../../scenario-narrative/references/characters.md)行动，视野之外仍付实际时间和成本。

把目标落实成可行动的现场：入口和出口、遮蔽与暴露、距离和高度、危险物与脆弱对象、可操作设备及知情渠道。地图与文字能支持采用的移动、观察和搬运；精确几何交[空间设计](../../scenario-space/references/spatial-design.md)。对每个承诺的策略，写所需准备、实施对象、对方能感知什么、有效范围及代价，规则数据另交P6。

策略差异可以来自分散注意、改变地形、切断补给、保护操作者、利用既有弱点、换取时间或转移保护对象。提供实际依据及可察觉线索；不设只有猜中作者唯一招式才有效的无源弱点。聪明行动按条件结算，既不自动成功，也不为维持对抗临时增加免疫。

<a id="src-coc-40"></a>

## 2. 避战、降级与撤离

在承诺存在选择的现场，实际给出能判断风险及采取行动的机会。避战可由绕路、交涉、隐蔽、移走争夺物或提前取消条件实现；代价按世界条件写，不默认绕路无损，也不把所有策略最终汇成同一战斗。

撤离具体核出口、追击路径、伤员／物件搬运、掩护、交接、追击者意愿及何时停止。规则尚未核时，只能说明设计意图与需求，不能宣称一定逃脱。撤离后更新位置、暴露信息、资源、关系及剩余威胁，保留已经救出的人、取得的材料和对方已经消耗的条件。

没有退路也必须有设定和开局前提依据，并让可感知的风险进入实际内容；内容承诺之外不临场加封锁保留高潮。提前解除威胁时取消相应战斗，已消灭的敌方不为原场面重新出现。

<a id="src-coc-42"></a>

## 3. 结算真实后果与交规则配置

分别结算任务目标、人员状态、物件／结构损坏、资源消耗、公开或私人知情、关系及责任。获救、负伤、成功撤退与未能阻止破坏可以同时成立。失败反馈给出已经发生的变化及可行动范围；伤势或精神后果按具体系统与约定内容处理，不用隐藏惩罚账目到结尾推翻成功。

P6需求附实际行动与对象：采用系统／版本，行动顺序与耗时，移动／观察／射程或其他必要尺度，协作与对抗，伤害／状态，撤离与追击，失败、重复及停止。交[通用规则](../../scenario-rules/references/rules-design.md)后，对影响目标、策略或逃生的配置返回现场复核；采用COC才加载[COC适配](../../scenario-rules/references/systems/coc/rules-design.md)。未知的决定性处理保持未核，本页不宣称完整支持所有战斗规则。

<a id="src-coc-44"></a>

## 4. 产物及作者自查

交连续可用的冲突场景：局势与预警→各方目标→现场与策略→避战／撤离条件→结果与后续→P6需求及采用配置。无战斗的冲突保留目标、可选行动与后果，不填伤害字段。

按本作承诺选正常冲突，以及避战、撤离、提前达标或失败中相关情形，核动作是否实际可做、敌方如何获知、目标何时完成及成果是否延续。规则配置、纸面走查、实际运行与平衡效果分别记录。

**虚构例，仅用于说明方法：**看守想拖住访客直到增援抵达，访客只想带伤员离开。现有后门可搬运伤员，但需要一人扶持、一人开门；访客可以谈判争取准备、让同伴开门或承担正门暴露风险。看守是否追出取决于其已知消息和守岗目标。若伤员已完成转移，就结算救援；不要求继续击倒看守。具体时序、对抗与受伤处理仍须按采用系统配置。

来源：原COC混合参考中的目的与后果原则原位承接，本轮补写跨规则的策略、避战撤离和配置交接方法；该转译不把COC数值或SAN推广到全部作品。
