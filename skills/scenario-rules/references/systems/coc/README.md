# COC适配入口

只有项目实际采用《克苏鲁的呼唤》（COC）时读取本目录。当前迁入的是既有COC第7版框架下的配置方法，不是完整规则书，也不表示其他系统、版本或全部房规已获支持。系统尚未确定时先用[通用P6](../../rules-design.md)明确规则采用和权限，不默认读本适配。

进行COC数据、裁定、规则卡或特殊机制时读[rules-design](rules-design.md)：保留规则约定→调查员与对象数据→行动／线索分类→基准判定→RP现场调整→结果与特殊处理→KP表与复核七工序。局部任务使用有关工序及依赖，整P6按阶段合同完整交付。角色一致性同时读[执行接口](../../character-configuration.md)及narrative中的两步总方法；机制设计同时读[通用机制方法](../../mechanisms.md)。

登记本项目实际版本、可选项、自订和已核条款；源稿给出的外部规则链接是待使用时核验的依据入口，不代表本轮迁移重新查过当前规则。新配置精确数值、伤害、SAN、派生值或例外须按所用资料实核；未核决定性项保留未完成，不能凭记忆称官方值。已有角色卡不擅改，普通角色建议不冒充预设整卡。

推理和战斗按作品侧重均有设计责任，使用实际采用的COC流程；不为凑工序强造战斗、谜题或SAN消耗。伤情影响能力、人手、负载、路线与披露，救活不等于恢复全部功能；SAN与异常、认识和情境相称，不因失败替玩家决定长期人格。具体状态、数值和安全约定按版本核验。

主持过程读[facilitation](../../../../scenario-play/references/facilitation.md)，最终主持资料整合归production；本目录交规则依据、默认裁定、机制与同版KP参考，不另行接管世界事实或玩家决定。文本自查、独立审阅、非作者实际运行和真人桌测分别记录。
