# 1. 已有理论能支持到哪里

<a id="src-inference-design-16"></a>
## 1. 已有理论能支持到哪里

最接近完整设计骨架的是Justin Alexander的揭晓清单、三线索法则和节点式调查。可以从这些已有方法开始，再用探究与证据分析完善单目标进程，用游戏体验设计约束线索安排。下表区分原方法和本稿的转译，不声称存在一套现成的“五部分统一理论”。

| 现有理论／方法 | 支持本稿的部分 | 使用边界 |
|---|---|---|
| [Revelation Lists](https://thealexandrian.net/wordpress/40978/roleplaying-games/random-gm-tip-using-revelation-lists) | 先列希望玩家形成的结论，再配置取得信息；区别线索接触与结论形成 | 本稿增加剧情用途、竞争解释、证据限度和双层状态；不是逐字照搬 |
| [Three Clue Rule](https://thealexandrian.net/wordpress/1118/roleplaying-games/three-clue-rule) | 防遗漏、误读、取得失败造成的调查瓶颈 | 原作者强烈主张至少三条；本稿取其容错思想，不把三条当逻辑充分性或普适配额 |
| [Node-Based Scenario Design](https://www.thealexandrian.net/creations/misc/node-design/node-design2.html) | 用地点、人物、事件等调查节点和连接支持不同顺序、多路径 | 节点可达图不等于证明依赖图；能去下一处不等于已经推对 |
| [GUMSHOE：Clues vs. Leads](https://pelgranepress.com/2020/02/21/clues-vs-leads/) | 区分引路、推进必需信息和理解内容，减少取得关口 | 其规则是系统内机制；在COC中迁移设计原则须另核规则，不自动照搬取得方式 |
| [Dewey：How We Think，第六章](https://www.gutenberg.org/cache/epub/37423/pg37423-images.html) | 从困难、问题、假设、推导到观察检验的探究循环 | 本稿状态是设计与观察工具，不是所有人的心理时间表 |
| 竞争假设分析与逻辑推理 | 将同一材料置于不同解释下比较，查诊断力、缺证及边界 | 详见[目标与认知阶段研究](../../scenario-writing/references/common/provenance.md#history-4230084330f7)；不把实务分析方法当事实必真算法 |
| [Golman与Loewenstein：Information Gaps](https://www.cmu.edu/dietrich/sds/docs/loewenstein/Information%20Gaps%20published%20version.pdf) | 用已意识到的问题组织未知、注意与继续获取信息的动机 | 支持明确问题的设计取向；不保证每个玩家必好奇或必采取同一行动 |
| [MDA](https://www.cs.northwestern.edu/~hunicke/pubs/MDA.pdf)与洞察研究 | 从预期体验反推玩法和反馈，区分“想通的感觉”与解答质量 | 爽感类型及投放矩阵是本稿综合，不能凭理论宣称游戏实测有效 |

研究按原著、原作者设计文、官方规则说明及原始研究整理。完整出处、实际读取范围和迁移限度分存[研究入口](../../scenario-writing/references/common/provenance.md#history-d421bfb28677)。技能提供审读流程和公平回报检查，不能作为学术实证。

<a id="src-inference-design-33"></a>
### 1.1 五部分是否足以构成整个基础

五部分能够组织推理设计的主体：要理解什么、怎样逐步理解、凭哪些信息、亲手推理有什么回报，以及怎样安排接触机会。它们是相互连接的设计维度，不是五个独立工序。要作为可运行调查剧本的推理基础，还须明确下列横贯条件；它们沿原阶段使用，不新增四个开发阶段。

| 必须交代的条件 | 它为什么不能省略 | 相关方法与补足接口 |
|---|---|---|
| 世界规则与玩家可用知识 | 作者知道的规则或专业常识若玩家无合法入口，材料再多也可能推不出；目标成立还依赖对象、时间和规则范围 | 第2.1、3.3节及模板登记前置知识、适用范围与真实入口 |
| 目标的证明结构与可解性 | 一堆线索可能只有支持、无法区分竞争解释；目标之间的连接也不能靠累计答对代替 | 第3.3—3.4、6.1节及负证据条件核充分性，并给完整OR路径例 |
| 玩家主动调查与世界反馈 | 玩家会提出作者没列的查法；世界、角色与材料要按其真实条件回应，并允许认识先用于有限行动 | 第8.1节核预设外查证及轻量运行循环，联查移动、可达与真实后果 |
| 呈现、容错与验证 | 字面不清、专业解读缺失、材料未分享、骰点失败和提前识破会改变实际可推范围；文本自洽不等玩家会读懂 | 第8.1及11节区分阻点诊断与证据、呈现、运行、体验验证 |

因此，本稿的判断是“五部分可作为主干，配以上述条件组成可制作的工作框架”。这不证明它穷尽所有推理玩法。相对固定事实调查的采用范围，主干外的历史、空间、NPC基础事实和规则仍由对应阶段提供；本能力负责检查接口够不够，而非另写一套世界。

<a id="src-inference-design-46"></a>
### 1.2 迁移、融合、游戏特化与需求扩展分别在哪里

下列标签说明本稿如何形成，可重叠：**保留**为采用原方法的核心做法；**融合**为将不同方法重组为共同对象与接口；**游戏适配**为按互动调查、角色限知、规则和玩家选择改变用法；**需求扩展**为响应用户五项和当前开发约束而增加字段或关系。不使用这些标签宣称全球首次提出或已经实证验证。

| 具体设计 | 归属及实际变化 |
|---|---|
| 按预期结论配置线索、检查调查出口 | 保留揭晓清单与节点法的核心；原方法本身已经服务游戏，不能把其游戏性都记为本稿新增 |
| 取得冗余与独立证明分开 | 融合三线索容错、来源依赖与证明组合；取“三条”背后的容错用途，另核各充分组合，不直接套固定配额 |
| 从剧情用途拆行为、目的、关系和操作目标 | 在预期结论上融合故事需求、证明边界与行动门槛；按用户要求扩展目标组合和剧情接口 |
| 事件整合与单目标R0—R5双层记录 | 融合探究循环与用户阶段想法；六工作状态、J/U和事件整合卡是本稿组织方案，允许跳层与回退 |
| 一手/二手、载体真伪、陈述准确性、可靠性、功能分轴 | 融合来源分析及线索功能；适配NPC误记、真载体载谎、布置现场与玩家重新解释，回应用户的欺骗与功能需求 |
| 目标状态×信息作用×提供方式矩阵 | 融合认知进程、线索功能与互动取得；矩阵是本稿综合，不是Dewey或GUMSHOE原表 |
| 固定物证不任意浮动、秘密不自动共享、可取消结果持续有效 | 调查游戏适配，其中固定事实、取消和来源边界受当前项目约束；不同玩法可另订边界，不冒称原GUMSHOE禁令 |
| 材料已够就认可提前判断、失去必要事实仍可有限行动 | 把证据标准、玩家主动性和事件后果结合；接触顺序不代替因果，不保证每桌经历同一反转 |
| 玩家前置知识、非预设查法和停滞诊断 | 需求扩展：“作者能解与玩家能解”的知识接口及真实调查响应；支持依据与转译范围见专题研究 |

游戏特化贯穿五部分：目标要产生真实选择，阶段允许乱序，线索受人物与世界约束，体验落实为可做的认识操作，投放回应玩家行动。第6节负责明确预期回报；其余各节共同提供产生回报的条件。

## 调查与推理：材料、证明、认知和行动

职责：证明、线索与认知章程用于有调查目标的互动作品；一般悬疑剧本可借用公平呈现与证明分析。“七类推理／行动联系”与“由联系到游玩”可按需用于其他互动任务，只读取相关局部节。人物知情在[interactive](../../scenario-play/references/interactive.md)，阶段编制在[workflow](../../scenario-writing/references/common/workflow.md)。

完整推理目标、双层认知、多轴线索、充分组合、阶段投放和事件试填见[推理设计](inference-design.md)。本页作为总览；局部七类联系仍在下文。共用表写`Stage.R1`（认知问题化）与`Link.R1`（线索提供），避免R编号混用。

<a id="src-investigation-7"></a>
## 四层分离中的推理层

先分清正在写哪一层，再检查各层如何连接：

| 层 | 回答的问题 |
|---|---|
| 故事 | 实际发生什么，人物为何行动？ |
| 推理 | 受众或玩家通过什么知道这些事？ |
| 异常 | 存在哪些可操作的规律？ |
| 恐怖呈现 | 受众或玩家实际感知什么？ |

各层连接要有因果来源。幕后心理可以写在作者资料；进入玩家判断时，还须有实际可得的材料。后台真相、神秘学术语或全知叙述都不能替代信息取得过程。

关键结论之前，先呈现观察、信息来源和推论过程。NPC 可能隐瞒、说谎或误判；有相应知情依据的 NPC 或档案，也可以直接提供局部事实。

检查一份材料是否过度包办身份、年表、动机、异常与解法。按实际问题分配证明工作，口述和文件都可使用；不设每份文件最多包含几项关键信息的通用上限。

把“玩家理解了”落实为实际认知动作。按当前问题选用以下活动：

- 比较并排除近邻解释，即同样能解释现象的其他合理说法。
- 用可取得的时点重建时间线，排列现场与动作先后。
- 对应物件、痕迹、位置与人物。
- 重构承诺、债务、亲缘、利益与权力关系。
- 让文件、照片、口供与物证交叉鉴证。
- 提出可观察的预测，再选择验证或证伪。

每项交代玩家所需材料、可比较的差异和结论限度。例如，要排除“物件是后来移入”的解释，就需给可比较的时间或痕迹，而不只是作者后台的一张时间图。人物卡也须转为实际材料，才能供玩家判断。

当前问题只需采用相关活动。主动实验保留为可选路径，基础推进仍可由探索、交谈、目睹和目标行动成立。

<a id="src-investigation-37"></a>
## 证明责任与否定

对每个结论写清材料证明到哪一步：只提示方向，支持某种判断，足以排除竞争解释，还是已足以据此操作？这些范围按实际问题判断，不靠标签自动升级。

物件被移动、某人实施、存在恶意和多人共谋是不同结论，分别检查依据。旧案责任不能独自证明当前行为，公开职务接触也不能独自证明秘密协作。反驳一种解释后，其他人格判断和异常规律仍需各自依据。

重要传闻记录最初来源、传播者、哪些内容为直接见闻，以及有何独立互证。多份口供、报道或重复答复若来自同一来源，仍是同一事实依据；它们可以另行证明消息怎样传播、谁曾接触消息。

专业经验可以提供有条件的建议。涉及暗道、隐秘事实或安全结论时，仍写明实际知识来源和适用范围。

要用“没有发现”支持否定结论，先说明：若对象存在会留下什么痕迹，实际检查了哪里，以及痕迹能否保存、能否观察。检定失败或一次未找到，只能记录本次检查结果。

误区可以部分正确，拥有真实依据，也可能曾帮助玩家。再用与其证明范围相称的反证揭示边界；误区数量和误判后的回报按作品需要设计，回报也不必是物资。

<a id="src-investigation-51"></a>
## 线索作用与最低充分集

按目标核材料的来源、功能、重要性及取得／理解难度；同源重复可防漏，不能自动增加独立证明。详细定义、最小充分组合与AND／OR检查见[推理设计第3及5节](inference-design.md)。旧称“最低充分集”与“最小充分组合”指同一对象：相对目标和前提，移去必要成员便不再充分，不是固定条数或全局最少条数。

失败后核实际替代的范围和共同关口；不保证所有目标仍能证实。无法查全仍可保护、暂停或合法退出，记录相应未知。

<a id="src-investigation-57"></a>
## 认知阶段与信息释放

事件整合与单目标认知分别记录，已取得、玩家确信、证据支持和行动用途分开。双层进程与R0—R5定义、阶段投放矩阵及停滞响应均以[推理设计第4、7—8节](inference-design.md)为准。

正常、主动调查与追加公开沿真实载体、人物知情和状态提供；已有材料够时认可提前判断，兑现改变与取消，不按预定章节扣信息。事件进程接[互动](../../scenario-play/references/interactive.md)，完整制作接[流程第4步](../../scenario-writing/references/common/workflow.md#src-workflow-269)。

<a id="src-investigation-63"></a>
## 七类推理／行动联系

<a id="src-investigation-65"></a>
<a id="seven-links"></a>

七类是源方法的操作分类，分类帮助找缺口，不作为每线配额：

局部适用：A1—A4可服务非调查互动的合作、任务与状态联系；R类在确有信息、探索或解释需求时采用。调用本节不意味着必须编证明章程或最低充分集；一般叙事／主题并置可直接使用narrative的分析视角。

| 类别 | 作用 | 边界 |
|---|---|---|
| R1 线索提供 | 增加信息、重估旧事实、改变解释 | 来自实际事物与行为反馈，有来源和证明范围 |
| R2 探索导向 | 指向人、地点、物件或事件 | 给理由与接近切口，不指定唯一任务顺序 |
| R3 猜想筛选与收束 | 核竞争解释、缩范围、汇核心问题 | 正当有限排除，收束理解而非固定结局，可有未知 |
| A1 人际关系影响 | 改变合作、保护、隐瞒、控制等 | 按人物立场回应，不以查完故事自动发好感 |
| A2 行动关联与条件改变 | 协作、争夺、阻碍与机会 | 具体到人手、材料、路线、独处等，不混同是否知道 |
| A3 行动指导 | 提供可用经验、方法与风险切口 | 支持决定，不给强制解题口令 |
| A4 世界状态与事件进展 | 获得、转移、消耗、修复物件及改变路线事件 | 持续结算促成、阻止、延迟和取消，不强迫升级全局危机 |

同一联系可有多个作用，仍是同一联系。A2是行为互相影响，A3是如何知道可做什么，A4是实际留下什么变化。生活接触、合作、条件变化不新增第八类；旧十机制不重复计数。

<a id="src-investigation-83"></a>
## 由联系到游玩

先把联系写成一条可追踪的过程：来源事实或行为→受影响故事线的反应或解释→玩家可感知表现→接触或介入→持续结果。注明必要前提及事实状态。

再检查玩家接触并介入、未接触、采用其他合理方式三种情形。完成时应能说明各自可见什么、能做什么、留下什么结果。主线对支线的反向压力、弱联系和人物独立欲望也一并保留。

理解可增加交易、操作、准备和风险识别；行动反馈可回到推理，允许行动先于全解。不把大量听背景而无法行动，或大量操作但不知意义当作丰富度。基础推进不依赖唯一NPC、单骰或全查支线，深入操作可以获得额外优势。纯情感小线不强求推理／行动循环。

## 题材、主题与具体呈现

按[主题规范](../../scenario-narrative/references/theme-presentation.md)将体验作用、实际接触、成立前件、中性对照与证明边界合入现有目标／线索／场景卡。先保证正文可读及来源成立，再检查情绪与行动效果；按任务只填必要字段，不另建全部负面化配额。
