# 成品验证与资格

先按[一般审核](review.md#src-review-27)绑定对象版本、实际读取范围和作者／审核身份。本页维护审读组织、验证矩阵与资格；空间、媒体、规则、语言等判据仍读对应唯一领域方法并实际执行，不以本页的检查名称代替领域检查。制作方执行入口在[production-qa](../../scenario-production/references/p8/production-qa.md)。

<a id="src-coc-74"></a>
记录实际做了什么：AI主持模拟、工具执行、非作者KP运行和真人桌测各有自己的证据。读过技能或写完任务书，只代表准备或交接完成。

<a id="src-p8-maps-media-185"></a>
## 展示证据与覆盖范围

先制作一个代表区域和一个狭小区域，放在整层图里与实际提供或已采用的参考图并排看，确认设计和阅读质量后再扩展。没有参考图时，依据已声明的俯视符号、尺度、层次和版式标准审小样，不声称做过参考对照，也不因缺参考停下常规制作。检查项包括：房间用途可辨、家具组合合理、门口不堵、标注可读、资源不误导、KP／玩家图一致。

全量做资产存在、链接、图像解码、几何和数据一致性检查；视觉检查说明实际看过哪些全图、局部、最小房间、长标签和打印页。PDF 不只检查封面：全量核文本和图片加载，再按风险查看页面；只抽样视觉检查时如实写抽样范围，不宣称逐页已审。

完成标准同时包括“设计有用”和“文件可用”。家具数量、脚本退出码、使用某技能均不能单独证明美观、可读或布局合理。

## 4. 角色化审读与修复

| 视角 | 读什么、怎么查 | 输出 |
| --- | --- | --- |
| 用户／实际使用者 | 找资料、开地图、多窗格阅读、导入保存、材料分发 | 操作任务、卡点、实际截图或记录 |
| 产品经理 | 信息归属、入口重复、状态、跨页流程、工具组合和适配 | 问题位置、影响、简化或调整建议 |
| 读者 | 初次读完整背景、人物、场景和线索 | 理解断点、歧义、跳读和缺少的信息 |
| 编辑 | 结构、因果、语言、角色声音、时代与条件 | 实际段落问题和修订核对 |
| KP 冷读 | 凭成品准备与运行关键场景、偏离和收束，不靠作者口头补充 | 必须临场补什么、哪里无法裁定或找不到 |
| 前序开发者 | 对照采用稿核人物、机制、几何、证据和变更 | 覆盖与差异，需回写的上游对象 |
| 项目统筹 | 各成果同版、问题闭环、交付完整、范围和限制 | 当前结论、未完项、发布条件 |

用户已要求委员会时按要求组织独立席位。否则这些是检查视角，不强制固定人数和轮数。独立审核者应看到实际稿件与必要来源，不只读作者总结；无实际独立席时明确为自审，不伪称委员会。

问题记录至少含对象／版本、位置、观察事实、影响、严重度、修改、复验和状态。先修阻断，再修重要体验，最后处理表现细节。每轮因未关闭问题或新改动触发；不为了凑“多轮”反复签通过。

## 5. 验证矩阵

| 对象 | 全量检查 | 有代表性的实际操作／视觉检查 |
| --- | --- | --- |
| 正文与索引 | 条目覆盖、锚点、内部引用、来源、实体唯一、条件和数值一致 | 冷读因果、关键场景及偏离，查找任务 |
| 地图 | 所有文件可解码、图入口、房间与门路、资源和状态、玩家导出秘密扫描 | 整图、狭小和密集区域、标签、家具与打印比例 |
| PDF | 全文提取覆盖、页数、图片／字体加载、目录和版本 | 代表页、复杂表格、换页、长词条、地图和末页；抽样范围明确 |
| 玩家材料 | 全部存在、独立资源闭包、原文一致、秘密和元数据扫描 | 实际单件预览、复制后打开、导出和分发条件 |
| 媒体 | 图像解码、音视频时长／解码、引用路径、许可和版本 | 肖像一致性、场景符合事实、实际播放及可读替代 |
| 工作台（选用时） | 数据结构、输入边界、导出完整、布局和状态序列化 | 真实点击、搜索、拖放、滚轮、返回、窄窗和零 Tab |
| 保存与迁移（承诺时） | 文件清单、校验和、完整记录、缺失与旧格式处理 | 新路径离线运行、导入导出往返、服务重启、恢复到新空间 |

脚本通过说明检查过的结构约束成立；截图说明实际所见画面；审读说明阅读范围。三者不能互相冒充。纸面推演、AI 模拟、非作者 KP 运行和真人桌测分别记录；一个关键场景通过不自动覆盖整部作品。

## 交回制作方的结果

按本轮完整P8／窄文件合同列适用和不适用对象，绑定真实文件／指纹、审核身份、方法／环境、实际结果及证据。结构检查、图像解码、视觉查看、声音听审、载体操作、非作者主持和真人游玩分别列覆盖，未做留未测；不能从记录中的pending或旧报告补授资格。

问题给具体位置、事实、影响和严重度，责任方实改同版正文／数据／文件，原审核者读取修改及影响对象后才关闭。审核者参与写稿的范围保自审或非盲资格。阶段要求独立验收时，由真实未参与该步编写者执行；委员会、人数和轮次按项目要求而非本页通用配额。结果足以让制作方判断哪些承诺已满足、哪些仍未完成，不能只给平均分或“已检查”结语。
