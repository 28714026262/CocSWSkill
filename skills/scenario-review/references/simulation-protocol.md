# 独立互动模拟协议

<a id="src-review-131"></a>
## 独立互动模拟协议

用于调查型互动作品的AI模拟或角色分席走查，检验信息、推理和运行接口；不要求所有剧本使用，不因文本审读就取得游玩实测资格。先设计席位的基线和权限，再运行。

| 席位 | 可知范围 | 预先声明的特性、能力与操作基线 |
|---|---|---|
| KP | 本轮世界事实、路线条件、可调用来源和运行规则 | 按真实探索回应，处理非预设查法、消息、岗位及取消；只给当次实际可得范围，裁定说明依据，不因没猜到直接补谜底或重启已取消灾害 |
| 读者 | 与声明观察视角匹配的实际公开内容及必要情境 | 冷读对象、关系、可信范围、比较切口和歧义；不读后台答案、目标充分组、作者功能标签或玩家推断，不把独立阅读当实际操作能力 |
| 玩家 | 公开情境、角色可用知识、本人实际取得或合法分享的信息 | 声明探索偏好、风险取向、记录／分享习惯、可用技能、允许动作与技巧边界，自主查法、假设和行动；不靠现实专业知识越过角色可知，不保证NPC合作 |

特性构成可观察的探索差异，例如先问人或先查现场、谨慎止险或继续比较、主动整理或容易漏分享；不是给低智商标签或故意漏关键卡。每席输入、能力与策略在运行前明示，不用测试后补设定解释结果。

三席每轮分别使用独立初始化的上下文，登记各席输入包、角色知识及可读范围，核启动历史而非仅限制后续打开文件。KP只取得当前版后台、规则和声明起点，不带上轮探索轨迹、失败诊断或对玩家预判；读者和玩家不继承统筹者后台历史或旧轮推断。不能确保隔离时记具体已知范围及非盲复查资格，不称独立初见。

独立保留必要游戏互动：玩家行动／问话与KP实际回应逐步往返。隔离的是内部分析、评审、后台答案及旧轮记录流入未获准席位。KP每次回包注明实际接收者、共同公开／私得／合法分享和有限内容；读者只收其声明视角可见的材料，不夹玩家假设、作者目标标签或KP后台理由。组内公开域和个人域分开，未分享私得的合集不等于任何角色已经可知。

1. **冻结对象。**记版本、合法起点与路线、资源、本轮问题和停止边界；后台真相与证明标准仅给KP及事后评审。
2. **合法抽选。**随机可用于探索顺序、可同时进行的事务、合法查法或实际分享顺序。要求随机时，先按当时状态、角色信息、路径、能力、岗位形成候选，使用明确方法，记候选范围、方法和实际结果，按方法留种子或抽取序列。只有一项记单一选择，无候选处理阻点，不增造动作。指定反例另标，不冒充随机；不越过进度、前件、人物知情或物理可达，不随机给正确结论或不存在的线索。
3. **动作与回应。**玩家提交实际行动，KP核条件给具体公开内容与反馈，玩家更新假设和下一行动；读者按其视图取得对应公开材料并独立分析。玩家可提出预设外有依据的查法；状态、消息和资源改变后重核抽选范围，条件事件按真实前件结算，不随机强启。现实讨论时长不自动成为惩罚时钟。
4. **封存再比较。**同轮读者和玩家不互读推断或评审；组内合法交流按渠道更新。停止后先封存各席记录，再比较实际取得、前提和方法、证明充分性、误填未知，以及认识改变的选择、风险、许可或关系。靠后台泄漏、补答案或无依据猜测答对不算设计成功；未解全案但合理止险不自动失败。
5. **实改后新轮复测。**定位证据、呈现、运行、理解入口或体验问题，改对应层并同步；三席按新版本重新初始化，KP不携旧轮诊断／玩家推断，读者和玩家不以知答案上下文假装初见。修订进入本轮正式材料，旧轮轨迹不作隐含提示；无法隔离则记非盲复查。

每轮最少记录版本、各席输入与特性、起点、随机候选／抽选、逐步投放与实际接收／分享、假设与依据、读者歧义、KP干预、判断及选择后果、问题和复测结果。先一条基本路线，再按风险用合法随机及关键反例扩大覆盖；次数由本轮承诺和实际问题决定。

**单轮停止**可按已完成观察范围、玩家合法退出、资源或路径不可继续、未制作前件使真实裁定无法继续等预先声明条件触发。遇制作阻断封存最后可裁定状态，不临时添世界事实把测试跑完；未决和退出保留真实结果，不要求收齐或答对。**返修迭代停止**以本轮适用须修实际修改并复测关闭为准，未关闭或无法验证项明列，不无限重复或降标准凑通过。AI模拟不代替真人的恐惧、满足、疲劳或社交体验记录。
