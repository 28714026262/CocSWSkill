# 人物运行模型与发展

本页是五部分人物模型及发展更新的唯一方法源；适用于一般叙事，互动作品再落实当前运行条件。构建时按[叙述空间与认识目标](character-construction.md#src-guide-construction-80)选择展开深度，展现时用[六步流程](character-presentation.md#src-guide-presentation-36)。人物不必全员填写完整运行卡。

<a id="src-contracts-35"></a>
## 重要互动NPC

依[人物模型](characters.md)，在同一张卡中分组记录：

- 身份与空间：公开身份、正常到场理由、出现位置和移动条件。
- 五部分人物依据：按[同页定义](#src-guide-construction-13)记录当前需要的内容，并标认知来源、时间、确信程度及变化依据。
- 当前调用：没人问时的下一项行动、可见预警、所需物件与岗位、改变／取消条件；接班、缩任务或短问后的可用能力。
- 互动接口：愿披露的范围、利益与风险、筹码、合作条件，以及离场后的影响。

完整卡只用于当前重要运行者，其他人物记录必要部分。主持应能凭卡判断下一步，无需补造关键心理或世界事实。

消息更新直接附在相关事件中：谁发送、当次实际接收者及有限内容、来源与时间、是否实际听取／听懂及相信多少、怎样反应、成本与可察觉痕迹。世界实际接收与玩家获知分别记录，只有可听条件时不填实际收到；后台已明确接收而玩家未确认，不阻断人物按实际接收更新。共同公开、私得和实际分享分别记录。承诺、等待、开始和完成的状态依据引用原事实ID，具体岗位／消息边界见[互动](../../scenario-play/references/interactive.md)。

**轻量填写示例：**以下内容仅在这个虚构示例内成立，不是可直接写入项目的事实。仓库上午开放，值班员周守有钥匙；访客实名登记后可以入内。

| 本例使用项 | 示例填写 |
|---|---|
| 身份与位置 | 周守，值班员；上午在仓库门口接待访客 |
| 性格 | 办事细致，登记缺项时会补问 |
| 立场 | 完成值班，按已有开放规定接待访客 |
| 认知 | 知道今日开放规定，来源为值班通知；不知道访客的调查目的 |
| 关系 | 对陌生访客保持工作礼貌，尚无私人信任或恩怨 |
| 行动 | 有钥匙，可以核登记并开门；访客不登记时，说明规定并继续值班 |
| 披露与合作 | 可以告知开放规定；涉及访客目的时只按实际听到的内容回应 |

这个场景不涉及完整生平或旧案，因此省略。若后续需要他离场、传信或改变立场，再补相应条件与依据。

## 五部分人物运行模型

五部分的完整定义及构成对应见[底色、立场、认知、关系与行为](#src-guide-construction-13)，重要互动NPC据此使用同一卡；以下保留实际运行的更新与调用边界。

人物听到消息后，先判断相信多少、是否已经确认，再依据目标、关系与能力决定行动；听到、相信、确认和行动分别记录，不自动连锁。关心某人不代表支持其全部目标；发生冲突也可能仍有感情或义务。同盟之间不自动共享秘密，按实际目睹、交流或有依据的推论分别更新知情。

关键事件的触发、理解、更新及后续按[人物发展检查](#src-guide-construction-27)处理。人物可以误判或拒绝相信，玩家已经取得的证据仍然有效。

人物出现在玩家眼前与离开视野后，都使用同一套行为依据。沙盒空间较大，注明常见地点、出现理由、接近方式，以及接触机会怎样变化。箱庭空间集中，注明人物当前位置、移动条件、接近或回避谁、如何回应互动。

对影响当前事件或线索机会的人物，将行动模式落实为当前可调用内容：此刻想做什么、已知什么、没人问时会做的下一件事、可见预警、所需物件与岗位，以及何时改变或取消。只补当前段需要的内容，不复制人物传记，也不要求全量日程。玩家不提问、人物拒答或提前止险后，主持仍能依据同一卡推导可解释的后续。

行为按能力、地点、意愿和资源成立。持续护理、守危险入口或搬护中的人物，不默认同时提供长供、深读或别处劳力；先核实际接班、缩任务或短问条件。分别记录承诺、等待、开始实施与完成：承诺接班不等已交班，答应传话不等对方已知，说会回来不等已经返回。可见局部动作与完整行动结果的取得范围按[推理设计](../../scenario-inference/references/inference-design.md)处理。

能接近人物与人物愿意说什么分别判断。只记录当前运行需要的内容，小角色无需完整日程或全量关系矩阵。完成检查：主持能凭卡片解释人物此刻为何在这里、知道什么、接下来会怎样做。

<a id="src-guide-construction-13"></a>
### 底色 立场 认知 关系与行为

| 模型部分 | 本方案如何使用 | 评价要点 |
|---|---|---|
| 性格／人物底色 | “底色”指既有模型中稳定的底层性格倾向，不另设第六项；说明惯常怎样理解处境、对待他人与处理困难 | 有持续可辨的倾向，优点与错误可以相联系，不只列好坏形容词；不同条件下保持人物连续性 |
| 立场 | 记录此刻的目标、态度、所维护的利益及相互冲突时的取舍；目标完成或重大情境变化后，可延续或调整 | 能解释当前选择；变化与延续均有依据，不把短时情绪自动当成价值转变 |
| 认知域 | 记录与当前选择相关的已知、所信、误解、来源及确信程度，自我认识也按实际内容分析 | 听到、相信、确认与行动分开；不以作者或玩家知识替人物知识 |
| 人际关系 | 针对具体对象记录情感、信任、利益、义务、依赖、权力及冲突，分别看双方 | 关心不等于支持全部目标，冲突不自动消除感情，关系影响行为和传话但不自动共享秘密 |
| 行动模式／行为模式 | “行为模式”与既有“行动模式”同义；结合前四项及能力、资源、身体、风险、岗位与空间，推导主动行动和条件反应 | 能解释无人问时做什么、受阻后怎样应对、何时停止或改做别事；在屏离屏依据一致 |

五部分共同作用，不是“有某底色就必做某动作”的机械连锁。能力与情境是行动成立的条件，不能由性格强烈补足体力、物件、时间或权限。运行字段按当前需要编制，简要人物可合写，不强建完整日程。

构成目录与模型的对应按实际作用处理：身份、经历和社会处境解释性格、立场及资源的形成；欲望、利益和价值支持立场及取舍；自我认识进入认知和自我解释；关系进入具体对象；能力、身体与当前处境限制行动。一个构成部分可以影响多项，已有内容只维护一次。

### 人物发展与弧光如何检查

人物弧光作为发展检查，回到同一模型中分析，不另建人人必经的成长模板。先区分历史怎样形成开局、当前实际发生什么、受众后来才知道什么。揭晓旧罪改变受众认识，不自动表示人物发生了变化；受伤、返幼等身体状态变化，也不自动等于人格转变。

| 检查环节 | 在同一人物中记录什么 |
|---|---|
| 起点 | 稳定底色、开局立场、实际认知、关键关系及惯常应对 |
| 触发与考验 | 实际遇到的新信息、目标完成／失败、代价、关系回应或条件变化 |
| 理解与消化 | 人物相信了什么、怎样解释结果，是否承认、回避、合理化或仍不确定 |
| 选择与更新 | 哪项立场、认知、关系调整，哪项延续；注明触发依据与行为条件 |
| 后续与余波 | 重推行动模式，检查后续言行及结果是否支持这次变化或坚持 |

当前互动运行中保留底色连续性，主要复核立场、认知与关系，再推导行为。人物可改变一个目标、停止某种手段、调整对某人的信任，也可受考验后坚持原有立场；不由一次让步宣布彻底悔改。需要重新定义既定底色的长期历史发展，回人物构建提出有依据的修订，不在局内借弧光临时颠覆。

正向、负向、局部改变、拒绝改变或稳定坚持均按作品需要检查；这些是分析方向，不是每人必备的弧线类型配额。互动版写条件支持的发展方向，按真实行动选择与更新；PC未来的思想和决定由玩家掌握。保持稳定的人物可通过考验显露分量，不要求三级、四级人物拥有完整变化过程。
