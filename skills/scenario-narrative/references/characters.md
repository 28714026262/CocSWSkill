# 人物运行模型与发展

本页维护互动人物的当前调用与更新。完整人物定义、五维分析与发展检查统一由[人物构建](character-construction.md#character-definition)维护；从同一三部定义抽取运行所需内容。构建时按[叙述空间与认识目标](character-construction.md#src-guide-construction-80)选择展开深度，展现时用[六步流程](character-presentation.md#src-guide-presentation-36)。人物不必全员填写完整运行卡。

<a id="src-contracts-35"></a>
## 重要互动NPC

依[三部人物定义](character-construction.md#character-definition)抽取当前可调用内容：身份、位置及到场理由；当前认知及来源、诉求和双方关系；主动行动、预警、岗位、物件、许可、披露与合作条件，以及改变或取消的依据。已有定义只引用或生成同版速查，不另设必填五栏卡。小角色按当前互动所需简写，主持应能据此判断下一步，无需补造心理或世界事实。

消息更新直接附在相关事件中：谁发送、当次实际接收者及有限内容、来源与时间、是否实际听取／听懂及相信多少、怎样反应、成本与可察觉痕迹。世界实际接收与玩家获知分别记录，只有可听条件时不填实际收到；后台已明确接收而玩家未确认，不阻断人物按实际接收更新。共同公开、私得和实际分享分别记录。承诺、等待、开始和完成的状态依据引用原事实ID，具体岗位／消息边界见[互动](../../scenario-play/references/interactive.md)。

**运行速查示例（不是人物定义的固定卡序）：**以下内容仅在这个虚构示例内成立，不是可直接写入项目的事实。仓库上午开放，值班员周守有钥匙；访客实名登记后可以入内。

| 本例使用项 | 示例填写 |
|---|---|
| 身份与位置 | 周守，值班员；上午在仓库门口接待访客 |
| 性格 | 办事细致，登记缺项时会补问 |
| 立场 | 完成值班，按已有开放规定接待访客 |
| 认知 | 知道今日开放规定，来源为值班通知；不知道访客的调查目的 |
| 关系 | 对陌生访客保持工作礼貌，尚无私人信任或恩怨 |
| 行动 | 有钥匙，可以核登记并开门；访客不登记时，说明规定并继续值班 |
| 披露与合作 | 可以告知开放规定；涉及访客目的时只按实际听到的内容回应 |

这个场景不涉及完整生平或旧案，因此省略。若后续需要他离场、传信或改变立场，再补相应条件与依据。

## 同一人物定义的运行与更新

完整定义及分析见[人物构建](character-construction.md#character-definition)，重要互动NPC从同一定义抽取当前调用内容；以下保留实际运行的更新与调用边界。

人物听到消息后，先判断相信多少、是否已经确认，再依据目标、关系与能力决定行动；听到、相信、确认和行动分别记录，不自动连锁。关心某人不代表支持其全部目标；发生冲突也可能仍有感情或义务。同盟之间不自动共享秘密，按实际目睹、交流或有依据的推论分别更新知情。

关键事件的触发、理解、更新及后续按[人物发展检查](#src-guide-construction-27)处理。人物可以误判或拒绝相信，玩家已经取得的证据仍然有效。

人物出现在玩家眼前与离开视野后，都使用同一套行为依据。沙盒空间较大，注明常见地点、出现理由、接近方式，以及接触机会怎样变化。箱庭空间集中，注明人物当前位置、移动条件、接近或回避谁、如何回应互动。

对影响当前事件或线索机会的人物，将行动模式落实为当前可调用内容：此刻想做什么、已知什么、没人问时会做的下一件事、可见预警、所需物件与岗位，以及何时改变或取消。只补当前段需要的内容，不复制人物传记，也不要求全量日程。玩家不提问、人物拒答或提前止险后，主持仍能依据同一卡推导可解释的后续。

行为按能力、地点、意愿和资源成立。持续护理、守危险入口或搬护中的人物，不默认同时提供长供、深读或别处劳力；先核实际接班、缩任务或短问条件。分别记录承诺、等待、开始实施与完成：承诺接班不等已交班，答应传话不等对方已知，说会回来不等已经返回。可见局部动作与完整行动结果的取得范围按[推理设计](../../scenario-inference/references/inference-design.md)处理。

能接近人物与人物愿意说什么分别判断。只记录当前运行需要的内容，小角色无需完整日程或全量关系矩阵。完成检查：主持能凭卡片解释人物此刻为何在这里、知道什么、接下来会怎样做。

<a id="src-guide-construction-13"></a>
### 五维分析入口

底色、立场、认知、关系与行为的唯一完整定义见[人物构建](character-construction.md#character-model)。五维用于分析，人物正文按[三部定义](character-construction.md#character-definition)组织；本页不另维护模型或固定卡序。

<a id="src-guide-construction-27"></a>
### 发展更新入口

按[人物发展与弧光检查](character-construction.md#character-model)区分历史形成、当前变化与受众后来知道。长期经历可有依据地改变倾向；当前互动沿采用设定更新，不由一次让步或检定重写人格。具体展开见构建主文。
