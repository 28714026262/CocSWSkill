# 人物构建理论与塑造规范

版本：v1.3-skill.1｜2026-10-24｜统一解构、历史形成与三部完整定义；展现与互动运行分别调用对应方法。

用于一般叙事中的人物分析、设计与修订，互动作品在此基础上增加运行条件。人物塑造的目标，是让角色在作品中成为可以辨认、理解并值得继续认识的人：设定之间存在联系，能够产生属于他的判断与行为，并通过作品得到实际呈现。

人物构成是分析目录，不是全员必填清单。先确定人物获得怎样的叙述空间、受众需要认识到什么程度，再选择展开内容；人物的复杂程度与塑造质量分别判断。本文的目标、分层和检查方法是结合文献与文学实例形成的工作框架，不是任何单一理论的原有分类。

<a id="src-guide-construction-9"></a>
## 人物模型与使用顺序

本方案统一维护解构方法、五维分析概念与三部成稿模板；[互动运行](characters.md#src-interactive-19)及[认知与关系更新](../../scenario-play/references/interactive.md)维护消息、许可、岗位和空间条件的更新方法；正式技能参考见[互动人物运行](characters.md)。文学构成目录用于追问依据，分级用于确定展开深度，评价用于定位问题，展现用于落实接触；这些工作共用同一个人物。

<a id="character-model"></a>

### 底色、立场、认知、关系与行为

| 模型部分 | 本方案如何使用 | 评价要点 |
|---|---|---|
| 性格／人物底色 | “底色”指既有模型中稳定的底层性格倾向，不另设第六项；说明惯常怎样理解处境、对待他人与处理困难 | 有持续可辨的倾向，优点与错误可以相联系，不只列好坏形容词；不同条件下保持人物连续性 |
| 立场 | 记录此刻的目标、态度、所维护的利益及相互冲突时的取舍；目标完成或重大情境变化后，可延续或调整 | 能解释当前选择；变化与延续均有依据，不把短时情绪自动当成价值转变 |
| 认知域 | 记录与当前选择相关的已知、所信、误解、来源及确信程度，自我认识也按实际内容分析 | 听到、相信、确认与行动分开；不以作者或玩家知识替人物知识 |
| 人际关系 | 针对具体对象记录情感、信任、利益、义务、依赖、权力及冲突，分别看双方 | 关心不等于支持全部目标，冲突不自动消除感情，关系影响行为和传话但不自动共享秘密 |
| 行动模式／行为模式 | “行为模式”与既有“行动模式”同义；结合前四项及能力、资源、身体、风险、岗位与空间，推导主动行动和条件反应 | 能解释无人问时做什么、受阻后怎样应对、何时停止或改做别事；在屏离屏依据一致 |

五部分共同作用，不是“有某底色就必做某动作”的机械连锁。能力与情境是行动成立的条件，不能由性格强烈补足体力、物件、时间或权限。运行字段按当前需要编制，简要人物可合写，不强建完整日程。

构成目录与模型的对应按实际作用处理：身份、经历和社会处境解释性格、立场及资源的形成；欲望、利益和价值支持立场及取舍；自我认识进入认知和自我解释；关系进入具体对象；能力、身体与当前处境限制行动。一个构成部分可以影响多项，已有内容只维护一次。

### 人物发展与弧光如何检查

人物弧光作为发展检查，回到同一模型中分析，不另建人人必经的成长模板。先区分历史怎样形成开局、当前实际发生什么、受众后来才知道什么。揭晓旧罪改变受众认识，不自动表示人物发生了变化；受伤、返幼等身体状态变化，也不自动等于人格转变。

| 检查环节 | 在同一人物中记录什么 |
|---|---|
| 起点 | 稳定底色、开局立场、实际认知、关键关系及惯常应对 |
| 触发与考验 | 实际遇到的新信息、目标完成／失败、代价、关系回应或条件变化 |
| 理解与消化 | 人物相信了什么、怎样解释结果，是否承认、回避、合理化或仍不确定 |
| 选择与更新 | 哪项立场、认知、关系调整，哪项延续；注明触发依据与行为条件 |
| 后续与余波 | 重推行动模式，检查后续言行及结果是否支持这次变化或坚持 |

稳定倾向有适用时期，长期经历可能改变性情、自评和价值排序，须说明形成过程；当前互动以采用设定为依据，主要复核立场、认知与关系，再推导行为，不能一骰重写人格。人物可改变一个目标、停止某种手段、调整对某人的信任，也可受考验后坚持原有立场；不由一次让步宣布彻底悔改。需要重新定义既定底色的长期历史发展，回人物构建提出有依据的修订，不在局内借弧光临时颠覆。

正向、负向、局部改变、拒绝改变或稳定坚持均按作品需要检查；这些是分析方向，不是每人必备的弧线类型配额。互动版写条件支持的发展方向，按真实行动选择与更新；PC未来的思想和决定由玩家掌握。保持稳定的人物可通过考验显露分量，不要求三级、四级人物拥有完整变化过程。

<a id="src-guide-construction-43"></a>
### 本轮分析与讨论次序

1. 分级：确定预定展开深度，主人公及视角身份单独标注；先不按写作质量升降级。
2. 逐人：用五部分模型核基础、重点与亮点，检查欲望排序、行为边界、历史形成、本局发展及未知条件。
3. 重叠：比较底色、立场／诉求、认知结构、应对方式、叙事作用与发展路径；不只比较职业和身世。
4. 关系：逐对核双方诉求、权力依赖、信息与许可、冲突和实际变化，再重推相关行为。逐人阶段先记录已有关系，深入联查放在本步。
5. 展现：调用[人物展现逻辑](character-presentation.md)，安排实际接触、顺序、技巧与留白。
6. 验收：核同版设定、实际呈现及实际受众认识，区分作者检查、独立冷读与运行反馈。

人物等级比例需要独立样本研究，本轮不以理论、单部P8或候选分级代替统计；评价系统使用基础、重点、亮点及上述模型说明缺口，不追加未经定义的统一权重或合格分。

<a id="character-definition"></a>

## 完整人物定义：三部分成稿

五维是分析同一人的角度，三部是组织连续可读正文的方式，不是两套竞争卡序。先从已有行为、关系、生活和经历解构，形成这个具体人的画像，再说明其形成与当前状态。画像或人物母版是分析所得的联系及局部参照；下方写作模板是成稿结构，两者不同。类型不是临床诊断、心理测量、犯罪预测或成长处方。借用画像库时用中文说明借什么、哪里不同，不以编号或类型替代人物。

### 第一部分：人物解构、画像与历史

将身份、底色、生活态度、普通满足、兴趣、自评、待人方式、价值取舍与惯常应对写成有联系的人。生活不是额外填空清单，帮助也不必全是赎罪或交易。已确认外貌可以自然融入，不从肖像补经历。

按重要时期写当时处境、知道或相信什么、想做成什么、为什么可能选择这种办法，以及实际后果。区分客观事件、人物当时或事后的信念与自述、作者对行为的心理解释；自然使用“他以为”“他后来这样解释”“从行为可作这样的理解”，不必机械三栏。自述不自动等于事实，作者解释不能变成可取得的新证词。条件、他人选择与偶然因素有独立作用，不能把结果全归性格。

接着写历史保留或改变了什么：倾向、自评、信任范围、目标排序和应对可能不同程度偏移，也可能只有短时情绪。画像解释历史，也受历史检验；解释不通就调整画像或解释，不补事实保护类型。不能把当前防御投射成一生如此。归纳通常先注意什么、怎样应对、何种反馈能使其调整及仍坚持什么，写适用范围而非心理算法。有限史料允许有限画像，不为填空编童年、创伤、兴趣、完整自评或临终愿望。

### 第二部分：关系、认知、立场目的与行动条件

按项目已定义人物范围检查双方，有实质联系详写，其余可分组注明材料不足，不固定人数、不强造相识。区分既有接触、间接关联、条件性未来接触与未有材料；未知私交不抹掉已定同车、交接或目击。一方见过不强定另一方识别，一方信任不等双向信任。双方各有什么理解、期待、利益、义务和实际回应，个人稿不替对方决定未发生的选择。

说明亲见、亲闻、转述、推测、误信、未知与不愿说，解释它们如何影响当前想得到、保住或阻止什么。目的可以冲突，对不同对象的策略应有依据。知道、说出、相信与公开承担分别看；亲密不自动共享秘密，作者知道不等角色知道，角色知道不等受众已取得。

能力、身体、资源与权限先用普通语言定性：实际会什么、不能什么、伤势如何限制、能调用什么。区分知道办法、具备能力、愿意执行与此刻有条件执行；职业、善意和亲密不自动增加知识、物件、同意或权限。数值、状态代码留第三部，不能为量化方便改已定事实。

### 第三部分：表现、变化与规则应用

开头说明人物等级、篇幅与出镜重点。分级约束作品笔墨，不衡量人的价值；可在准备时先用于取舍，但成稿位置在本部。沿作品已有分层：核心支持深入认识，重要人物支持关键取舍与关系反馈，局部人物让一种相处和一处选择成立，有限人物可只保一个有效反应；不规定人数、字数或场次配额。历史死者仅通过既有材料与有据回忆展示，不新配当前行动。

按需要写常态、受请求、拒绝、纠正、揭露或危险时的差异。案例有情境、短对白/动作或材料展示、对方回应及实际后续，数量服从笔墨，不强制每人三例；动作不作测谎，台词不讲人格学。玩家打断、拒绝、提前解决或条件改变时调整或停止，不补事故保演出。PC未来思想与决定归玩家。

给出可能改变判断的事实、反馈或关系事件，变化到哪、代价与余波是什么、仍保留什么。允许局部改变、负向变化、拒变或稳定；认识反转、选择/关系改变与身体状态分开。一次认错、帮助、受伤或受罚不改全人，已定历史不重开未来分支。可扩展、可反转、有趣按笔墨作编辑检查，不是心理测量，不要求人人全强。

按实际所用规则量化第二部已有能力与限制：相关属性技能、派生值、装备、伤势、移动、行动占用及能力撤销条件。既有数据不为画像擅改，不授未知信息，也不能用检定替代同意与真实人手。缺依据说明待配或不适用；一般叙事、历史及无相关规则互动者无需虚构战斗卡。必要事件与规则使用链接可留本部。

来源清单、采用状态、审修资格、回写进度、哈希与维护日志放独立记录，不是人物第四部。人物认知来源、事件关联、实际岗位与操作条件属于人物内容，不能以清理维护为由删掉。

<a id="character-template"></a>

## 可复制的精简模板

方法与判定依据见上节。按材料与笔墨合写短段，不把提示变问卷；历史或有限人物可直接说明材料不足。

```markdown
# 人物名称

## 第一部分：人物解构与历史
写具体画像，融入生活、自评与倾向的联系。
写重要时期的处境、认知、选择与后果，再写历史的保留与偏移。
归纳有适用范围的思维行为；区分事实、自述与作者解释。

## 第二部分：关系、认知与当前处境
检查项目相关人物与双方差异，保已定关联与未知。
写当下认知、立场目的及策略；定性说明能力、身体、资源与权限。

## 第三部分：扮演与规则应用
交代等级笔墨、扮演建议、可选案例、变化与余波。
依实际所用规则量化，或说明不适用/待配；保事件与规则查阅入口。
```

## 一 理论依据与适用边界

| 文献 | 可借鉴的认识 | 使用边界 |
|---|---|---|
| 亚里士多德《诗学》第六章 | 人物性格与行动、选择相联系，性格说明不能替代事件中的实际表现 | 原论述主要针对悲剧，不把其情节优先及道德要求推广为全部文学的唯一规范 |
| 福斯特《小说面面观》人物部分 | 圆形人物能以可信的方式令人惊讶；扁平人物有鲜明、易辨认和易记忆的价值 | 圆形与扁平不直接等于成功与失败，不要求所有人物具有同等复杂性 |
| 詹姆斯·费伦的人物三方面框架 | 区分拟人方面、主题方面与构造方面：人物作为可能存在的人、观念或社会经验的载体、作品中的人为构造 | 三方面是分析角度，不是三个必填模块，也不要求每个人物平均承担主题 |
| 阿历克斯·沃洛克《一与多》 | 人物在有限且不均等分配的叙事注意力中得到呈现，应结合整体人物系统理解其位置 | 人物空间不只等于字数；本规范的四种叙述空间及分配办法是综合应用，不冒称沃洛克原有分类 |
| 爱伦·坡1842年论霍桑《重讲一遍的故事》 | 短篇可围绕集中效果组织材料，各部分对整体印象作出贡献 | 主要适用于集中表达和有限篇幅，不据此要求所有长篇、群像和互动作品只有一种效果 |

来源及文学原文见第九节。下文关于作品的重点分析属于本框架的文本解读，与理论原命题分别理解。

<a id="src-guide-construction-66"></a>
## 二 人物塑造的目标

| 目标 | 判断内容 |
|---|---|
| 成立 | 在给定世界、经历和处境中，人物的认识与行为有可信依据 |
| 独特 | 经历、欲望、价值、关系与应对方式形成特定组合，能够与其他人物区分 |
| 连贯 | 不同阶段、关系和情境中的表现存在可理解的联系，变化有依据 |
| 主体性 | 人物有自己的感受、判断和利益，在实际余地内回应环境与他人 |
| 认识深度 | 按作品承诺的深度，人物经得起进一步认识；复杂人物允许受众修正原先理解 |
| 有效呈现 | 重要设定能够通过行动、言语、关系、叙述和后果被感知 |
| 适合作品 | 展开内容、复杂程度、叙述方式与所占篇幅适合人物的具体作用 |

可以理解不等于必须赞同；主体性不等于强大、主动或有能力改变命运。次要人物可以只建立准确鲜明的局部认识，不承诺无限心理深度；上述目标按实际叙述任务解释，不逐项平均评分。

<a id="src-guide-construction-80"></a>
## 三 先确定叙述空间与认识目标

<a id="src-guide-construction-82"></a>
### 3.1 分开判断三个方面

- 接触次数：人物出现一次、间歇出现，还是持续处于视野中。
- 内心开放程度：受众能进入其意识，还是主要从言行、关系和他人观察认识他。
- 关键时刻的分量：人物是否承担重要选择、关系转折、局势变化或情感落点。

这三个方面不直接换算。反复出现的人物可以始终保持神秘；只出现一次的人物也可能承担重大选择。角色作用、背景复杂度与实际展示篇幅分别记录，不由主配角称谓自动推导。

互动作品还应区分作者准备的内容、主持人所需依据、玩家可能接触的内容及本局实际呈现。按可预见的接触和行动范围准备，不把未发生的互动预记为人物已被充分展示。

<a id="src-guide-construction-92"></a>
### 3.2 按叙述空间选择重点

| 人物获得的空间 | 塑造关键 | 优先展开 | 可形成亮点的位置 | 通常可以省略 |
|---|---|---|---|---|
| 持续深入的核心人物 | 让受众逐渐认识并修正认识，建立跨场景联系 | 欲望与价值的相互作用、自我认识、重要关系、选择及后果 | 同一性格在不同处境中的展开，使此前言行获得新解释的时刻 | 无关履历、反复证明同一特点的场景、无助于认识的旁支 |
| 反复出现的重要配角 | 建立稳定而有厚度的独立存在 | 鲜明诉求、行为逻辑、一两段重要关系，必要时显露另一面 | 有生活依据的反差、独立于主角需要的判断、涉及自身利益的决定 | 完整成长史、全量关系、所有心理层面的解释 |
| 集中于少数场景的人物 | 使一个具体处境或冲突充分成立 | 眼前所求、实际限制、对他人的态度、具体反应 | 同时显露欲望、处境与性格的行动 | 全套价值观、远期目标、完整变化过程 |
| 短暂出场的人物 | 迅速建立存在感，准确完成局部作用 | 具体身份与现场状态、一种可辨认的应对方式 | 有意味的言行，与出场时机及当前事件的特殊联系 | 独立副线、创伤解释、成长弧线和完整人物档案 |

四种情形是工作上的侧重，不是文学价值等级，也不规定固定字数或场次数。短篇主角可以借一个集中行动呈现多方面联系；重要配角也可以保持稳定而不发生转变。

<a id="src-guide-construction-103"></a>
## 四 人物构成的分析目录

| 构成部分 | 核心问题 |
|---|---|
| 身份与社会处境 | 处于什么位置，拥有何种资源、权力、责任与限制？ |
| 经历与形成过程 | 怎样成为现在的人，怎样理解经历，哪些影响延续至今？ |
| 欲望与利益 | 想获得、维持、逃避或保护什么，不同诉求如何排序？ |
| 价值与判断 | 认为哪些事情正确、必要、可耻或不可接受？ |
| 性格与情感倾向 | 习惯怎样感受、理解和回应，哪些情境会改变其表现？ |
| 能力与局限 | 能做什么、知道什么，有哪些盲点、依赖和限制？ |
| 自我认识 | 如何解释自己，与实际行为及他人认识有何距离？ |
| 人际关系 | 双方怎样需要、影响、约束和误解彼此？ |
| 当前状态 | 过去的积累怎样成为此刻的生活、压力和行动条件？ |

按第三节决定哪些部分必须成立、哪些值得展开、哪些可以留白。没有成长、创伤或错误信念需求时，不添加对应内容；作者也不必先写满所有未展示部分。准备深度以支撑实际言行、关系连续性和会触及的问题为准。

<a id="src-guide-construction-119"></a>
## 五 人物组织的规范

1. 重要设定具有作用。身份、经历、价值和关系应影响人物的认识或生活；保留生活余量，但不靠履历条目数量制造深度。
2. 重要行为具有依据。结合当时认知、欲望、情绪、习惯与处境解释行为；依据可以延后揭示或保留歧义，但应经得起回看。情节需要只说明作者目的，不能代替人物理由。
3. 连贯允许变化。不同对象面前的表现需要关系依据，冲动与失常需要具体条件，长期变化需要过程，不要求任何处境下表现相同。
4. 矛盾具有联系。理解不同倾向怎样共存、何时冲突、如何取舍及造成何种后果，不将互相对立的性格词直接视为复杂性。
5. 经历不机械决定人格。同样经历可形成不同的人；人物对经历的理解、后续关系与反复选择共同参与塑造，不用单次创伤解释全部人格。
6. 认知有范围。人物按实际知道、相信或误解的内容行动，不自动获得作者知识，也不必准确理解自己。已有事实、文本支持的推断和新增候选分别标明。
7. 关系具有双向作用。双方各有诉求和认识，权力、依赖、历史与误解产生实际作用；一方不能只作为另一方的背景标签。

文学上的长期性格发展与互动运行时的状态更新分别处理。重要互动NPC的消息、许可与行动条件更新仍由[人物与消息规范](characters.md#src-interactive-19)维护；本文不把叙事变化当作临场任意颠覆既定人物的许可。

人物弧光的起点、考验、消化、模型更新及后续检查见开篇“人物模型与使用顺序”；对照稳定底色、立场、认知、关系与行为分析，不用单次认罪、受伤、揭晓或让步替代完整判断。

<a id="src-guide-construction-133"></a>
## 六 呈现与有限笔墨的取舍

具体方法统一见[人物展现逻辑方案](character-presentation.md)。先确定人物希望被认识的内容，再按“认识目标→承载内容→接触方式→呈现顺序→实际作用→强调与留白”组织，之后选择具体撰写技巧。

呈现要给重要设定提供可感知依据，允许直接叙述、内心、对白、行动、关系和侧面材料等不同手段。不同深度的人物按本次接触选择重点，保留稳定可靠、照护、幽默与日常等亮点，不要求人人反转、认罪或完成成长。少量笔墨优先支撑必要行为与关系，留白不能替代缺失的关键原因。

独立方案承接本节原有的集中承载、处境解释、重复增量、局部生活与后果位置五类方法，展开认识顺序、媒介与互动条件及成稿核对；本页继续维护人物构建与内部联系的理论依据。

## 七 文学实例与可迁移重点

以下为本框架对原作的分析，不作为唯一解读，也不把情节直接移植到项目。

| 人物与作品 | 原作中的具体依据 | 可迁移的塑造重点 |
|---|---|---|
| 伊丽莎白，《傲慢与偏见》 | 机敏与识人自信，遭遇达西来信后重新审视判断 | 核心人物可通过多次修正自我认识建立深度，不只陈列聪明与偏见 |
| 夏洛蒂，《傲慢与偏见》 | 接受柯林斯求婚，说明安稳生活的要求，并安排婚后相处距离 | 少数重要方面经选择、解释和生活实践印证，足以支撑重要配角，无须另配完整成长史 |
| 韦米克，《远大前程》 | 事务所的防备与利益判断，家中的照护、热情及私人建议 | 用不同生活领域的反差建立厚度，让处境支撑差异，不必完整追溯形成史 |
| 看门人，《麦克白》第二幕第三场 | 弑君后醉酒拖延开门，并想象自己守着地狱之门 | 短暂人物的声音与出场时机共同产生局部力量，不依赖私人传记 |
| 凡卡，《凡卡》 | 围绕写信呈现受苦、乡村记忆、对祖父的依恋及对寄信的天真认识 | 短篇主角也可借一个集中行动显露多方面联系，不由总字数机械判断塑造深度 |
| 利德盖特，《米德尔马契》 | 医学理想与对阶层、女性、生活体面的偏见并存 | 检查能力、价值和盲点怎样共同运作，避免用一个形容词解释全部行为 |
| 孔乙己，《孔乙己》 | 读书人身份认同、困窘生活，以及酒店中被取笑的处境 | 个性应结合社会位置、关系和自我认识分析，不将困境全部归为个人缺陷 |

<a id="src-guide-construction-155"></a>
## 八 解构流程与完成判断

每个人物按实际需要形成以下内容，可用短段落记录，不强制新增表格：

1. 叙述定位：接触次数、内心开放程度、关键时刻的分量；受众需要认识到什么程度。
2. 构成与联系：已有设定及其相互作用，说明怎样产生当前判断和行为；文本依据与推断分开。
3. 必须成立的基础：支撑实际行为、关系及本次接触所需的内容，缺失处保持未决。
4. 值得展开的重点：按叙述空间选取需要深入的部分，说明为什么值得占用笔墨。
5. 能形成分量的亮点：指向具体场景、言行、关系或叙述位置，避免只列抽象美德和缺陷。
6. 可以留白的部分：说明何处不必补、何处可简写，避免无依据暗示会有后续展开。
7. 呈现核对与问题诊断：区分设定中成立、作品已呈现和仅有作者说明的内容，定位缺失、薄弱、矛盾、重复及可发展部分。

完成判断以人物的具体任务为准：必要行为有依据，选定重点得到相称呈现，人物与其他人可区分，亮点有实际支撑，留白不妨碍当前理解。核心人物还应检查跨场景的认识增量与连续性；少量出场人物不以缺少成长史或完整内心展开判为失败。

人物不必具备创伤、秘密、善恶混合、成长弧线、复杂身世或讨喜性；不能仅因符合这些套路而判定塑造成功。角色的拟人、主题和构造方面分别考察，不以单一方面代替全部价值。

互动作品的具体运行要求继续按[人物与消息规范](characters.md#src-interactive-19)执行；可玩角色的耦合、介入和规则一致性另见[可玩角色设计](player-design.md)。准备的可能行为、作者预期与玩家实际选择分别记录，文学实例中的既定发展不转化为强制剧情。
