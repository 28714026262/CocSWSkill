# 媒体内容、资源与展示检查

检查绑定当前实际文件、采用版本和受众；从[任务书](asset-briefs.md)核承诺，再只执行当前媒体分支。不以文件数量、提示词、工具返回成功或解码通过替代内容及展示核验。

## 全量核资源和内容

逐件登记路径、类型、用途、对象ID、采用版本、受众／公开条件、编辑源、来源／许可、必要校验及检查状态。确认承诺文件实际存在且可读取；索引路径与真正交付路径一致。修订后重核文件与依赖、更新版本和校验，停用的旧件不得混作最新版。

| 当前对象 | 内容检查 | 实际检查与完成依据 |
|---|---|---|
| 位图／肖像 | 识别特征、时代、服装、装备、伤势和系列一致性 | 打开实际导出图，查看整体及关键细节，说明看过哪些件 |
| 场景CG | 时段、状态、人物站位、可见关键物；与文字及采用地图相容 | 看全图和风险局部，无提前泄露、无无源资源；装饰图不充当精确结构 |
| 手卡／文书 | 原文、数字、署名、符号、缺损、页序；证明边界 | 逐字比对，实际目标尺寸可读，复制／打印适用时实查；有可读文本替代 |
| 音频 | 来源、触发／停止、循环、信息与音量要求 | 解码和时长全量核；另记录实际听审范围、峰值、循环接缝与突兀变化 |
| 视频／动画 | 关键帧、文字／字幕、时序、声音和状态一致性 | 完整解码；按承诺实际播放并核画面／字幕／声音，注明未看／未听范围 |

音频可播放、静音时钟推进、波形存在和解码都不等于听过；视频缩略图不等于完整播放。不能听审时保留“未听审”及影响，不能用主观形容伪装听感结论。已验证编码也不能授予真人效果、可理解性或恐怖体验资格。

## 玩家净化与资源闭包

按准许内容白名单生成玩家件，包含所需图片、字体、字幕、音轨和其他依赖。逐件检查正文、隐藏层、可选择文本、注释、文件名、元数据、替代文字及附件有无后台秘密；管理索引和公开条件留KP侧。只打`player_safe`标签不能净化文件。多文件HTML须连同依赖目录交付；复制到独立目录或新路径实际打开，检查相对路径和离线需求。仅发送主HTML不等于发送整件材料。

## 交接与资格

交实际文件及必要源、同版索引、来源与许可、实际查看／播放范围、内容比对和缺项。图像生成、文件存在、解码、视觉审查、听审、软件中展示和真人使用逐项分别记证据。完整P8接入由[production](../../scenario-production/references/p8/maps-media.md)接收实际文件再验载体，不凭媒体自查授整体通过。领域内容缺口回采用源，审核协议及证据层次见[成品验证](../../scenario-review/references/production-verification.md)。
