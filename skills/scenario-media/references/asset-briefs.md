# 媒体任务书与制作输入

本页用于本次实际资产任务的范围和采用约束。先读本页，再选[视觉制作](visual-assets.md)或[声音／视频](audio-video.md)，最后执行[媒体检查](media-qa.md)。只做任务书时交可执行任务书，状态保留待制作；已承诺实际资产时继续到文件和实际展示，不以提示词结束。

## 从用途确定资产

记录对象ID、采用版本、实际用途和接收者：是让KP辨认人物、给玩家观察现场、阅读一份材料，还是播放氛围或传达信息？决定需要的媒体、尺寸／时长、静态或变体、输出格式、编辑源及交付位置。沿用项目的对象ID和知识记录，不以资源制作完成推定玩家已经看到。

逐项对照采用稿，给出文件／段落或指纹：

| 输入 | 制作时的处理 | 准备完成依据 |
|---|---|---|
| 固定事实 | 人物外貌、衣物装备、伤势；地点和时段；关键物与位置；事件已经发生还是可能发生 | 每个会影响理解的可见细节有依据或明确允许设计 |
| 载体原文 | 手卡逐字文本、署名、日期、数字、符号、页次与缺损 | 与采用原文一致；需要新字句先回内容源采用 |
| 证明边界 | 画面／声音能支持什么观察，不能证明什么；KP后台与玩家可见部分 | 不把猜测、虚构痕迹或已取消事件画成实证 |
| 受众与公开条件 | KP、所有玩家或特定角色；交付件所含知识 | 条件写管理索引，实际玩家文件只含获准内容 |
| 来源与权利 | 参考图、字体、录音、人物形象、第三方素材及允许用途 | 已知许可与待定项逐件列出，制作权限与公开分发资格分开 |

纸色、笔触、构图可以在授权范围内决定；血迹、额外门口、签名、时间戳、人物在场和可领取物会改变内容，须回责任源核实。无决定性输入时先做不依赖它的版式或候选，标出受影响资产，不能造事实填满。

## 风格和实际能力

按作品媒介、时代、受众和用途选择画风、色彩、字型、清晰度及感官强度；已有参考先实看，说明采用哪项，不把参考中无关事实复制进作品。人物系列保存已采用的识别特征；信息手卡以准确可读优先。精确门路、尺寸与剖面交[空间构建](../../scenario-space/references/map-construction.md)，氛围图读取采用几何而不成为新几何权威。

核当前可调用的工具、输入方式和实际输出能力：生成／编辑位图、排字与矢量合成、导出、播放或音视频编辑分别核实。选当前环境可用的专用工具或技能并读取其说明；写下工具名称和本次确实能完成的部分，不预设某API、订阅、声音听审或视频能力已具备。调用技能、执行工具、安装依赖和对外上传是不同动作，按已有任务授权执行。

## 代表件到批量

先选能暴露风险的代表件：肖像看识别特征，场景看关键物和可见范围，手卡看最小字及长文本，音视频看峰值／转场／字幕。实际制作并查看或播放代表件，按固定事实和风格修订后再扩量；单件任务直接以该件完成此步。批量不照搬上一作品的数量。

每件任务书最少能回答：采用什么→保什么→允许改什么→交哪个实际文件／源→给谁用→用什么工具制作→怎样核原文／事实和实际显示。交回时以实际资源索引替代任务书中的计划路径，并记录失败、修订及尚缺能力。
