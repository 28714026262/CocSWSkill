# 路线及不确定性

<a id="src-play-evaluation-290"></a>
## 11. 三类路线与不确定性

至少区分：基础可达路线、合法优秀路线、关键偏离路线。只承诺分析某一阶段时不强制做全游戏分支树，但至少检查影响结论的一个反例，例如提前识破、漏掉入口、成功取消危机、分队或拒绝可选任务。

每条路线分别给时间、图与S，不按未知概率混成一个期望总分。分支有实际频率数据时才可以另报分布及期望，并保留路线差异。

较快／参考／较慢时间情景必须重新运行积累、释放与疲劳，不能把同一张图横向缩放：更短的降温可能来不及处理线索，更长讨论也可能出现认知疲劳。证据不够时给估计范围与排序稳定性，不伪造统计置信区间。
