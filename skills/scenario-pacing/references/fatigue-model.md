# 活动丰富度与疲劳模型

<a id="src-play-evaluation-163"></a>
## 7. 活动丰富度、连续同类与疲劳

<a id="src-play-evaluation-165"></a>
### 7.1 分开三件事

活动类型占比p记录阅读、搜查、操作、讨论、交涉、聆听等；六方向x记录体验；语义变化n记录是否出现了有意义的新问题、新策略、新关系或新反馈。换房间但重复搜查不一定新颖；围桌讨论也可能连续经历不同的理解和情感。

丰富度用于诊断“是否有变化”，不自动给总分加多样性奖励。专注单一体验可以是阶段目的。新增名字、新线索或视觉刺激不自动抵消负荷。

<a id="src-play-evaluation-171"></a>
### 7.2 四类疲劳与单调指标

疲劳状态f∈[0,1]分别追踪：认知、紧迫、情绪、操作／身体。最后一项对数字操作、实体移动或长时间坐姿按实际启用。轮候／无有效参与主要进入单调与参与机会诊断，不把旁观一律视为疲劳。

负荷与恢复机会可按0—100分输入，允许小数，依据当前要求和实际条件判断；计算时除以100得到l、o∈[0,1]。参考锚点之间可给分。状态初值f0需要记录：新会话并不必然等于0，跨会话也不默认清空。已有0—1内部状态按原值参与计算，展示时标明百分制转换。

持续负荷记忆H_k以分钟计：当l_k≥0.5时增加Δt×l_k；否则按Δt×(0.5-l_k)×2减少，最低0。阈值只为初始工作设置。

    连续系数 C_k = 1 + b_k × max(0, H_k / τ_k - 1)
    生成率 g_k = η_k × l_k^1.5 × C_k
    恢复率 r_k = ρ_k × o_k
    f_k' = clip[f_k exp(-r_kΔt) + (g_k/r_k)(1-exp(-r_kΔt)), 0, 1]

r=0时改用clip(f+gΔt,0,1)。固定更新顺序：先用步前H和本步负荷求步后H，取两者中点计算C；再据恒定g/r解析更新f；评分采用步前后f中点；最后推进活动记忆与显示。跨负荷阈值或事件变化处分步。恢复机会并非强度低就成立：持续轮候可能无聊，受威胁的“休息”可能不恢复。四类o分别赋值，安全而高强度推理不自动恢复认知疲劳。自动计算以1分钟与0.5分钟对照，重要输出或排序改变时细分或报告不稳定。

初始参数仅作统一比较起点：η=0.012／分钟，ρ=0.04／分钟，τ=25负荷分钟，b=0.5，四类暂同值；不可宣称人群通用。η上下浮动50%、ρ上下浮动50%、τ取15／25／40进行敏感性检查；必要时按玩家及活动分别校准。

综合疲劳：F=100×[0.6 max(f_k)+0.4 sqrt(Σv_k f_k²)]，v在启用维度中和为1，默认等权。保留各分量与最高者，避免一项过载被冲淡。F是设计风险指数；玩家自报的疲惫单独展示。

实测若已观察到疲劳使某活动未发生，x按实际记录；不能再人为用同一F先缩释放量、再折损Q。完整模型只在Q中折损一次，且同时保留未折损Q0和实际体验。当前状态截到1后不记录隐藏恢复债，因此长期饱和后的恢复预测尤其需要校准。

### 7.3 同类持续与单调

对每类活动a建立连续暴露H_a：每步增加p_aΔt；当p_a<0.2且确有活动／体验转换时，每分钟减少1分钟，最低0。仅换场景标题不重置。

    M = clip[(1-n) × Σp_a max(0, H_a/τ_a-1)/2, 0, 1]

τ_a初始25分钟，按题材、活动和玩家调整。n是该步有意义变化程度，不能用“作者写得丰富”代替证据。丰富度可降低M，认知疲劳仍按负荷累积。热烈、精彩与疲惫可以并存。

活动H_a同样先求步后值，再用步前后中点代入M，最后保存步后值。n、p或实际活动变化处分段，不能用段末一次变化追溯消除前段单调。
