## 14. 内置工作表

复制后填写。适用于实际游戏、游玩大纲、条件上限剧情。先做A—D即可得到初步时间与结构诊断；E—H用于完整数值评估。参数含义见本文第4—11节和第17节参数注册。

状态：0＝确认没有；NA＝缺数据；N/A＝不适用。预测、观察与玩家自报分别填。下列空白表不含任何具体项目事实。

<a id="src-play-evaluation-358"></a>
### 14.C. 活动与时间

| 包ID／来源 | 玩家过程及结束反馈 | 较快／参考／较慢分钟 | 三情景各自依据 | 资源与依赖 | 与其他包重叠 | 世界时间 | 证据标签 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

路线汇总：现实会话____；游玩过程____；有效参与____；离桌休息____；全桌停顿____；各玩家轮候____。明确哪些已包含，不能再次相加。

填写规则：现实会话＝游玩过程跨度＋未纳入过程的离桌休息／全桌停顿／边界管理；这些加总项须互不重叠。有效参与是过程内至少一名目标玩家有效参与的区间并集，缺依据可填NA。个人轮候已在墙钟内，不再次相加。例如过程82分钟、离桌5分钟、未含管理3分钟，会话90分钟；即使某玩家等候8分钟，会话仍为90分钟。

用户目标是希望安排的时长，参考情景是按活动推估的结果，两者可以不一致。先独立估算，再判断是否要修改安排，不能为凑目标反向填数。

单主持分队的角色世界可同时行动，但两个各6分钟的主持包现实通常仍需12分钟串行；个人轮候包含在这12分钟里。复杂排程可查[时间例7.2（历史定位，原文不随包）](../../scenario-writing/references/common/provenance.md#history-91d13bf1a68d)。完整模式的T_ref应与积分轴同口径：上例90会话中的过程参考是82分钟，需登记后使用。

| 内容ID | 来源包／取得条件 | 即时体验 | 待处理方向／价值依据 | 释放条件／后段 | 实际加工与反馈 | 剩余／失效及原因 | 计分归属 |

价值单位是有效体验分钟，若无依据可只做连接诊断。来源段不预支后段收益。多种作用分清内容，不重复计一次突破。

<a id="src-play-evaluation-388"></a>
### 14.F. 分段体验与状态

| 起止分钟／来源包 | 模式 | 六方向实时a/q | 释放量及来源 | 当前目标服务G | 负荷l／恢复o／初值f | 活动占比p／变化n | Q0／Q／各疲劳F／M | 依据与不确定性 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

展示粒度与证据一致；区间值不插值为真实逐分钟。逐人可增加玩家ID。无逐人数据时标集体预测。

人工评分栏以0—100分填写并允许小数，附量表版本；a/q、l/o、g/h、n等进入公式时另记0—1归一值。结果栏按百分制展示：Q0／Q／F直接显示，方向、疲劳分量和M乘100显示；注明是人工评分还是模型计算，不把无依据的值补成0。

### 14.H. 一页结果与复核

>
> **现实时间：**较快____／参考____／较慢____分钟；此为____情景，非分位数。
>
> **当前判断：**____。**总分：**____（或“目前可评____，缺____，暂不计算完整分”）。
>
> **最突出负担：**____类，依据____；工作阈值以上持续____，参数____。

>
> **优先行动：**①____；②____；③____。无依据时少填或不填。
>
> **后效：**____处积累在____释放；____仍未处理，原因____。
>
> **适用范围与验证：**____；未覆盖____。

核对：时间不重复／路线合法／机会与发生分开／没有将NA填0／休息不被强迫填任务／不同玩家差异可见／总分非采样均值／显示与配置同版。
