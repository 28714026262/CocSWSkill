# 辅助技能选择与交接

职责：按实际目标选择辅助能力、交接产物及处理冲突。叙事、流程、证明和验证的定义仍在各领域；普通正文任务使用本包即可，只有需要专项能力时读本页。

## 三种整合方式

已转译方法在本包自包含使用：人物诊断在[narrative](narrative.md#可选人物诊断)，编辑与研究在[craft](craft.md#编辑分工与结构优先)，悬疑评审在[review](review.md#悬疑专项审核与修订层级)。这些方法来自其他会话实际采用的技能，按剧本与互动任务适配；转译不等于照搬原技能全部流程。

专项增强需要时从当前会话的可用技能目录找到下表名称，读取其当前SKILL及相关参考，确认其适用范围后调用。下表不是自动全加载清单，不能从本页描述推定某技能已安装、支持模型自动调用或工具可用。仅供用户显式调用的技能需按其调用方式处理；用户直接点名时遵从当前明确指令。找不到时使用本包已整合方法，说明尚缺的专用能力；不用安装和外部动作填补本轮未授权范围。

工具产物按实际请求制作：读取工具技能与给出任务书都不等于已生成资产或完成运行。主持、骰子、存档、图像与文档格式工具不变成每个写作任务的前置步骤。

## 按目标选择

| 目标 | 可用技能及调用边界 | 最小交接与完成依据 |
|---|---|---|
| 长篇虚构结构、人物或小说形式阅读稿 | fiction-workshop；其原范围排除舞台／影视和轻量单场，剧本借用本包转译方法，不强行启动完整小说流程 | 指定版本、保留事实、编辑层级、实际段落；交诊断／候选／授权实改，按请求停止 |
| 文学参照、领域或文化资料缺口 | creative-research | 具体问题、时期／地域、原材料、约束；交可用细节、来源可靠性、冲突、矛盾、缺口和待采用转译 |
| 历史纹理、时代错置 | historical-fiction-research；材料效用与可信度分别判 | 锁时代／地域／阶层、对象和核心可行性；交时代、语言、观念核查，未查处保留待核 |
| 有悬疑承诺的反转、伏笔和回收审核 | mystery-payoff-and-fairness-judge；量表按所用版本及项目说明，方法见review | 当前实际稿、先前已见材料、承诺与干预；交证据、证明限度、最高层缺陷和修订顺序 |
| 已明确要求批评论证 | critical-thinking-logical-reasoning；本轮取样未确认常用 | 原论证、结论、证据与假设；交逻辑问题及实际影响，不把其限制事实核查的原流程用于替代史实／规则研究 |
| 多案发散、选型或结构重起 | superpowers:brainstorming的目标校准与比较思路；一般创作用[七步循环](craft.md#七步深度发展循环)，软件技能整体流程只在真正的软件工作中适用 | 对象、缺口、约束、候选采用权限；交不同因果方案与选型理由，数量和用户参与按任务配置 |
| COC角色卡、规则接口、投骰或团记忆 | coc-trpg-skill；场景／NPC设计方法已与本包接口衔接，专用脚本仅在实际需要时调用 | 系统版本、既定人物／规则、玩家可知与KP私有分开；实际输出及规则核验资格分别登记 |
| 用户明确要求主持、开始／继续跑团或试玩 | coc-kp-host，或coc-trpg-skill的主持模式；选择一套当前主持协议，前者本轮未确认常用 | 可主持包及版本、参与者、公开／私有材料、当前状态、内容边界；真人运行、AI试玩和纸面推演按实际分别登记 |
| 中文正文整理与风格润色 | chinese-writing通用清晰表达；humanizer:humanizer为可选增强，本轮未确认常用 | 文字、受众、声音样本、不可改字段；交润色正文，核条件、事实和证明限度仍保留 |
| 项目计划、执行与多席协作 | superpowers:writing-plans、executing-plans、dispatching-parallel-agents、verification-before-completion有历史阅读记录；具体触发服从其原任务范围 | 剧本任务用[workflow](workflow.md)、[review](review.md)、[maintenance](maintenance.md)既有流程；不额外制造代码TDD、分支提交或固定代理数 |
| 真实历史地理展示 | historical-map | 核实地点／年代／坐标及精度、引用依据；地图展示和地理事实分别核验，虚构场所不伪配坐标 |
| 气氛、肖像或其他位图资产 | imagegen | 版本、外观约束、公开／私有信息、用途与实际参考；按图片请求生成／编辑并检查，不能凭生成画面认定几何可行 |
| Word／PDF阅读或主持文档 | documents:documents、pdf:pdf，按实际格式选择 | 当前定稿、受众、保留内容、字体／布局需求与资产可见性；实际生成并检查页面，文本完成与排版／导出未测分开 |

## 冲突与交接规则

原技能推荐的三幕比例、5—15候选、3—5场景、每结论三条线索及量表阈值，在本包中是各自语境的模型或配置，不升级成所有剧本配额。线索冗余按[investigation](investigation.md#线索作用与最低充分集)的推进风险判断；小说预写成长／结尾不能覆盖玩家选择。若用户专门要求采用某套模型，明确其范围，再与项目固定事实联查。

主持技能的菜单、逐轮长度、NPC队友、默认时代、房规、音乐与存档配置只作用于已选择的主持协议。写作任务交场景和条件，不自动开团；选项展示方式发生冲突时按当前用户约定选一种，不在两套协议间轮流切换。NPC能提出自己材料支持的猜想，不能成为KP答案传声筒；分队知情按实际交流更新。

每次交接带当前对象版本、任务、固定事实、采纳与待核状态、实际读取资料、玩家／KP可见性、请求产物、权限和未完成验证。接回研究／审稿／资产时，把事实确认、结构建议、候选呈现和实际测试结果放回各自轴；经采用再按[maintenance](maintenance.md)同步，不让研究报告、审稿意见或图片直接覆盖母版。

## 维护与来源

名称以当前环境目录为准，机器路径不进运行依赖。审计中的skill-session-evidence.json保存八会话的有限分页阅读证据；skill-sources.json记录本轮源文件及实际转译归属。当前文件指纹不是旧会话版本证明，成功阅读也不是使用效果认证。常用核心、阶段工具与未确认常用的可选增强分别登记；资料源缺失不阻塞本包核心写作，专用资产／主持能力缺失则如实登记。
