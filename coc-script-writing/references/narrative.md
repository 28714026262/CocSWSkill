# 一般叙事：故事、人物、支线与结构

职责：L1共同设计模型与原则；L2/L3继承。具体表达见[craft](craft.md)，互动人物运行定义见[interactive](interactive.md)。

## 人物与事件因果

从已有经历、当前处境、所知、所求、能力和机会解释行动。先补缺失事件与因果，再补心理、生活和关系；人设可反过来提出调整，但须区分确认事实与候选。人物选择产生故事，作者需要某个线索、命案或合作不能代替动机。

多人卷入同一事件时分别说明进入时点、利益与态度变化。共同行动可以来自不同心理。优点与错误可同源；真诚恩情和真实罪行可以并存，揭罪不自动证明所有善举虚假，合作也不等于原谅。角色可以识别真实细节却错误归责；能力、客观事实、所信和社会／机构认可分别判断。

一般剧本按需要借用性格、立场、认知、关系与行为倾向分析，完整五部分运行规格只作用于重要互动NPC。小角色可凭有特点的动作被记住，无需完整生平、秘密和人物弧。

## 可选人物诊断

人物行动无法从已有处境解释时，可借fiction-workshop的Want／Need／Wound／Lie问法分别检查外在所求、潜在内在需要、已有经历及可能错误信念。它是诊断镜头，不是另一套必填人物卡；对没有相关创伤或成长主题的人物可省略对应项。未知经历列缺口或候选，不补一场童年创伤来合理化任意动作；与五部分运行模型衔接仍用已有认知、关系和行为字段。

关系双向核双方从对方要什么、权力与依赖、误解、底线及当前变化；出人意料的行动由新信息、压力或已有特征支撑。正向、负向或平稳人物弧可作作者设计参考，互动人物的后续取决于实际条件，玩家的成长、悔改和牺牲保持可选择。

声音分析可核常用词、句式、注意对象、称呼与避谈话题，比较几段实际对白能否辨认说话者。缺声线样本就给候选而非声称一致性已核；路人不必建立完整声音档案。结构诊断、人物建议与表达润色的工作分工见[craft](craft.md#编辑分工与结构优先)。

## 需求先行与材料角色

先写需要补足什么及发生阶段：人物／主题／情绪／节奏，认识与解释，或行动空间。再决定主题问题、故事性质和重量；不从支线数或功能标签倒推。类型与作用不机械一一对应。

- 主线节点承担核心因果，不必另造个人谜案。
- 支线有自身当前诉求、冲突、选择与变化，同时进入整体。
- 关系线可短而重要，用具体关系行为成立。
- 背景提供厚度，不承诺独立完整发展。
- 预期情节是条件成立时可呈现的场面，不因精彩就成为独立故事。

选择前回答：缺口在哪一阶段、故事问什么、受众／玩家经历什么、结果改变什么、删除会失去什么。先让故事自身成立，再按互动层建立介入。可靠合作、正常生活、轻关系和纯氛围都可满足需求，不把丰富性全部变成旧案与秘密。

## 重量与删除测试

人物重要性、支线复杂度、前台展示篇幅分别控制。影响关键局势的照护线可以很轻；跨多年代的往事也可只是背景。丰富核心表示承载内容的能力，不是道德价值、出场次数或重要性排名。

需要分级时，可用源研究提案的两组可选判据；它们尚无跨项目实测认证：

| 轴 | 分级参考 | 判据 |
|---|---|---|
| 作用范围 | 主线风险／关键行动条件 | 改变当下主线风险或关键行动能否成立 |
| 作用范围 | 认知／合作／选项 | 改善理解、合作或可选方案 |
| 作用范围 | 情感／主题 | 主要表达情感与主题，仍可有充分价值 |
| 复杂度 | 重 | 持续冲突、多次状态变化与难以兼得的目标 |
| 复杂度 | 中 | 一项核心矛盾，经多次自然交汇发展 |
| 复杂度 | 轻 | 一项局部选择及明确回收 |

作用范围可重叠，重点说明主要变化；它不排序人物价值或玩家完成顺序。复杂度只对已形成发展的线判断，背景不因跨年代自动成为重线。关闸的一次选择可为核心作用且轻；信任冲突经几次交谈达成合作可为协作作用且中。前台篇幅再按体验承诺与注意力预算分配，不从作用范围或复杂度机械推算，也不设固定条数。

先确定主要作用，辅作用按需要添加：因果推进／阻碍、认知与排除、行动资源、关系立场、主题对照、情感世界、节奏学习。旧提案的“一主至多两辅”可作收束练习，不作为数量上限。没有物资或数值奖励不等于无价值；长线需要与投入相称的回报。

删除测试比较事件、理解、关系、情感四种损失；重复测试辨别多条故事是否都在查档、保名字或认旧罪，而没有不同当下行为和回收。调整优先使用已有事件、关系与空间，不先增加新旧案或陌生设定。

## 结构模型：总—分—总—分

这是源文的可选因果组织模型，适合多线危机与调查，不规定幕数：

1. 共同处境把不同问题带到同一作品，受众知道需要行动但尚不了解类别。
2. 局部故事各有诉求、转折与变化；按实际来源可有共同根，也可通过后续联系相互影响。
3. 连续交集使旧事、证据、人物和当前问题互改意义；中型交集可以多次发生，最大交集之后有执行与关系余波。
4. 人物在改变后的条件中选择，结局承接此前行动与状态。

一般叙事由作者安排关键动作；互动版本要给可取得材料和介入机会，不能以本模型强制调查顺序、全员大会或固定结局。一个单场短剧可以只呈现一项冲突和变化。

## 多线交织模型

旧十项影响机制是分析视角，互动作品可按需要借用[七类联系局部节](investigation.md#seven-links)的操作分类；非调查动作联系可只用A类，一般非互动或纯主题并置不必标R/A。证明与认知章程在有相应调查问题时使用，同一联系不按两套重复计数。

| 机制视角 | 实际应改变什么 |
|---|---|
| 生成／取消事件 | 某行动、机会或后果的成立 |
| 改变执行条件 | 路径、人员、成本或对象 |
| 竞争解释／排除 | 哪项认识受到支持或限制 |
| 意义重估 | 已有事实在新背景中的解释 |
| 关系传导 | 某人愿意承担的行动／风险及下一人的反应 |
| 外溢与碰撞 | 各自计划争同一时间、路线或资源产生的影响 |
| 风险识别与预备 | 观察后可预测或应对的局部危险 |
| 主题对位／反衬 | 同一问题下不同选择改变的评价 |
| 情感对象与节奏 | 可记住的人、生活、失去之物及呼吸空间 |
| 后果延续 | 人、物、伤情、关系持续进入后段 |

硬因果、认知、关系、主题情感边有不同强度。并置可互改意义而不共享物理事件；弱联系和真正无关的小事可保留。主线也对支线产生压力，不让支线轮流供答案。检查过密、工具化和全员阴谋化。

## 揭晓与结尾

揭晓能重估旧事实、引出值得追问的问题、改变行动或关系，不必全部覆盖。误会解除可以恢复合作，却不自动恢复信任、免除责任或归还生活。最大转折之后承接执行、取舍和余波；不无故开启需要重新调查的第二个主矛盾。开放结尾、继续冲突或悲剧服从项目承诺，不能强制牺牲来证明主题。

主题通过选择、行为与后果表达；普通自保、局部救援或不原谅可以成立。结尾说明实际变化、保留未知和人物此后面对的问题，不用作者道德判词代替因果。
