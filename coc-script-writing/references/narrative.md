# 一般叙事：故事、人物、支线与结构

职责：L1共同设计模型与原则；L2/L3继承。具体表达见[craft](craft.md)，互动人物运行定义见[interactive](interactive.md)。

## 人物与事件因果

先解释人物为什么在此刻采取这项行动，再发展心理、生活和关系。检查时依次问：他经历过什么，现在处于什么局势，知道什么，想要什么，有何能力和机会？

如果行动缺少依据，先定位缺失的事件或因果。人设也可以提出情节调整，但要分别注明已有事实与新候选。作者需要线索、命案或合作，只能说明创作目标；人物仍须有自己的动机。

多人卷入同一事件时，分别说明他们何时进入、利益如何变化、态度为何转变。共同行动可以来自不同心理；同一种性格特点也可能同时带来优点和错误。

真诚恩情和真实罪行可以并存。揭露罪行后，逐项判断哪些善举仍然真实，以及合作是否包含原谅。角色也可能看见真实细节，却把责任归给错误的人。核人物时分开记录实际能力、客观事实、本人相信的内容，以及社会或机构认可的说法。

一般剧本按需要借用性格、立场、认知、关系与行为倾向分析，完整五部分运行规格只作用于重要互动NPC。小角色可凭有特点的动作被记住，无需完整生平、秘密和人物弧。

## 可选人物诊断

人物行动无法从已有处境解释时，可借 fiction-workshop 的四个问法定位缺口：

| 问法 | 检查内容 |
|---|---|
| Want（外在所求） | 此刻想得到或保住什么？ |
| Need（内在需要） | 若故事涉及成长，人物尚未意识到什么需要？ |
| Wound（既有伤痛） | 已有经历是否影响当前选择？只使用稿中有依据的经历。 |
| Lie（错误信念） | 人物可能相信什么错误判断？该判断如何影响行动？ |

按问题选用即可。没有相关伤痛或成长主题时，省略对应项；未知经历列为缺口或候选，不能凭空补童年创伤来解释动作。诊断结果仍放回五部分运行模型的认知、关系和行为字段，不另建一套必填人物卡。

关系要从双方分别检查：各自向对方要什么，谁有权力、谁依赖谁，存在哪些误解和底线，当前事件改变了什么。出人意料的行动应能追溯到新信息、压力或已有特征。

人物弧指人物在故事中的持续变化。正向、负向或平稳人物弧可供作者设计参考；互动人物的后续按实际条件发展，玩家自行选择是否成长、悔改或牺牲。

声音分析可核常用词、句式、注意对象、称呼与避谈话题，比较几段实际对白能否辨认说话者。缺声线样本就给候选而非声称一致性已核；路人不必建立完整声音档案。结构诊断、人物建议与表达润色的工作分工见[craft](craft.md#编辑分工与结构优先)。

## 需求先行与材料角色

先写清本轮缺口及其发生阶段：需要发展人物、主题、情绪或节奏，需要帮助受众认识和解释，还是需要增加行动空间？再决定故事要问什么、采用哪种性质、发展到何种重量。支线数量和功能标签用于检查已有方案，不能代替这一步；同一类型也可承担不同作用。

- 主线节点承担核心因果，不必另造个人谜案。
- 支线有自身当前诉求、冲突、选择与变化，同时进入整体。
- 关系线可短而重要，用具体关系行为成立。
- 背景提供厚度，不承诺独立完整发展。
- 预期情节是条件成立时可呈现的场面，不因精彩就成为独立故事。

选择前回答：缺口在哪一阶段、故事问什么、受众／玩家经历什么、结果改变什么、删除会失去什么。先让故事自身成立，再按互动层建立介入。可靠合作、正常生活、轻关系和纯氛围都可满足需求，不把丰富性全部变成旧案与秘密。

## 重量与删除测试

分别判断人物重要性、支线复杂度和实际展示篇幅。影响关键局势的照护线可以很轻；跨多年代的往事也可能只是背景。

这里的“丰富核心”指一条线能承载多少内容。人物的道德价值、出场次数和重要性需要另行判断。

需要分级时，可用源研究提案的两组可选判据；它们尚无跨项目实测认证：

| 轴 | 分级参考 | 判据 |
|---|---|---|
| 作用范围 | 主线风险／关键行动条件 | 改变当下主线风险或关键行动能否成立 |
| 作用范围 | 认知／合作／选项 | 改善理解、合作或可选方案 |
| 作用范围 | 情感／主题 | 主要表达情感与主题，仍可有充分价值 |
| 复杂度 | 重 | 持续冲突、多次状态变化与难以兼得的目标 |
| 复杂度 | 中 | 一项核心矛盾，经多次自然交汇发展 |
| 复杂度 | 轻 | 一项局部选择及明确回收 |

使用表格时先判断作用范围，再判断复杂度。作用范围可以重叠，记录主要变化即可；它不决定人物价值或玩家完成顺序。复杂度只用于已经形成发展的线，背景跨越多年也不自动成为重线。

例如，关闸的一次选择可以影响核心行动，同时仍是轻线；信任冲突经过几次交谈达成合作，可以承担协作作用且为中线。最后按体验承诺和受众能同时关注的内容分配展示篇幅，分别说明理由，而非由前两项直接换算篇幅或固定条数。

先确定主要作用，辅作用按需要添加：因果推进／阻碍、认知与排除、行动资源、关系立场、主题对照、情感世界、节奏学习。旧提案的“一主至多两辅”可作收束练习，不作为数量上限。没有物资或数值奖励不等于无价值；长线需要与投入相称的回报。

删除测试：暂时拿掉这条线，分别写出事件、理解、关系和情感损失。重复测试：比较多条线的当下行为与后续回收，检查是否都在查档、保名字或认旧罪，却没有不同体验。

完成检查后，应能说明每条保留线的独有价值，以及重复部分如何调整。优先利用已有事件、关系与空间，再考虑是否确需增加旧案或陌生设定。

## 结构模型：总—分—总—分

这是源文的可选因果组织模型，适合多线危机与调查，不规定幕数：

1. 共同处境把不同问题带到同一作品，受众知道需要行动但尚不了解类别。
2. 局部故事各有诉求、转折与变化；按实际来源可有共同根，也可通过后续联系相互影响。
3. 连续交集使旧事、证据、人物和当前问题互改意义；中型交集可以多次发生，最大交集之后有执行与关系余波。
4. 人物在改变后的条件中选择，结局承接此前行动与状态。

一般叙事由作者安排关键动作；互动版本要给可取得材料和介入机会，不能以本模型强制调查顺序、全员大会或固定结局。一个单场短剧可以只呈现一项冲突和变化。

## 多线交织模型

下表保留旧十项影响机制，用来分析一条故事怎样影响另一条。互动作品需要落实操作时，可借用[七类联系局部节](investigation.md#seven-links)：动作联系可使用 A 类，有信息、探索或解释需求时按需使用 R 类。一般非互动作品或纯主题并置直接使用本表即可。

有调查问题时，再补证明与认知要求。两套分类是观察同一联系的不同视角，记录时保留一条实际联系，不重复计数。

| 机制视角 | 实际应改变什么 |
|---|---|
| 生成／取消事件 | 某行动、机会或后果的成立 |
| 改变执行条件 | 路径、人员、成本或对象 |
| 竞争解释／排除 | 哪项认识受到支持或限制 |
| 意义重估 | 已有事实在新背景中的解释 |
| 关系传导 | 某人愿意承担的行动／风险及下一人的反应 |
| 外溢与碰撞 | 各自计划争同一时间、路线或资源产生的影响 |
| 风险识别与预备 | 观察后可预测或应对的局部危险 |
| 主题对位／反衬 | 同一问题下不同选择改变的评价 |
| 情感对象与节奏 | 可记住的人、生活、失去之物及呼吸空间 |
| 后果延续 | 人、物、伤情、关系持续进入后段 |

联系的强度不同：硬因果会直接改变事件能否发生，认知、关系、主题或情感联系也可改变理解和体验。两条线并置时，即使不共享物理事件，也可能互相改变意义；弱联系和真正无关的小事按其价值保留。

检查双向影响：支线如何改变主线，主线又给支线何种压力？再检查三种风险：联系过密、人物只剩供答案的用途、所有人物都被拉进同一阴谋。

## 揭晓与结尾

揭晓能重估旧事实、引出值得追问的问题、改变行动或关系，不必全部覆盖。误会解除可以恢复合作，却不自动恢复信任、免除责任或归还生活。最大转折之后承接执行、取舍和余波；不无故开启需要重新调查的第二个主矛盾。开放结尾、继续冲突或悲剧服从项目承诺，不能强制牺牲来证明主题。

主题通过选择、行为与后果表达；普通自保、局部救援或不原谅可以成立。结尾说明实际变化、保留未知和人物此后面对的问题，不用作者道德判词代替因果。
