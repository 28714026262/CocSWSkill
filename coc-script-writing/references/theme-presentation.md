# 主题与线索痕迹呈现

版本：v0.1本轮同步稿，2026-10-10。依据用户已明确的主题倾向要求及本轮通过的整合架构编制，本轮采用与验收范围见[整合台账](../audit/20-integration-revision.md)。本页是通用维护源《主题与线索痕迹呈现通用规范》的同步参考，正文自包含，复制技能包后也可使用。

职责：把题材体验与主题作用落实到实际呈现。叙事因果、调查证明、互动状态和验证资格仍由各领域维护；本页按当前任务调用这些边界，不另建一套事实或证明规则。项目私有数量、人物与材料不迁为通用配额。

## 适用范围与调用时机

本规范用于把主题和题材体验落实到具体呈现。主题是作品通过人物选择、关系和后果持续追问的问题；题材倾向是受众在接触材料时预期经历的感受，如温暖、好奇、紧张、神秘或恐惧。两者分别说明，再检查如何共同作用。

| 层 | 本规范的用法 | 完成对象 |
|---|---|---|
| L1 一般叙事 | 按舞台、影视或其他叙事形式，把主题落实为人物行为、可见对象、声音及后果 | 受众可读、可见或可演的呈现；作者可安排角色行动与顺序 |
| L2 互动作品 | 在共同叙事基础上，说明玩家接触方式、可行行为、成立条件和状态反馈 | 可感知的场景与有实际作用的选择；后续依实际行动结算 |
| L3 COC | 继承 L1/L2，按作品承诺选择压抑、恐惧、神秘、异常、未知或破坏等倾向 | 与当前题材相符的重点呈现；调查、恐怖与系统接口按任务选用 |

COC 的题材名称不自动要求全部内容压抑。整体与重点场景形成所选倾向即可，普通资料、日常劳动、真实善意、清晰答案和恢复段可以保持平实。每条线索无需负面标签，也不设情绪元素、秘密或灾难的数量配额。

在设定体验目标、设计线索与痕迹、编写场景或审核呈现时调用。已有材料足够时直接优化呈现；尚缺决定性事实时先标明缺口。仅修改文字的任务完成文字范围，发现上游问题另列影响，不擅自改动世界事实。

## 从目标到实际呈现

按当前对象执行以下步骤。局部任务只处理受影响范围，整线或整阶段任务再检查组合。

1. **确定目标与基线。**记录当前稿、媒介、题材倾向和主题问题，列出已定事实、可改部分及请求产物。完成时能说明本轮希望受众经历什么，以及哪些事实必须保留。
2. **分配作用与对照。**按剧情线、关键场景和推理阶段安排重点倾向，指出哪些段落保持中性、提供对照或恢复。说明每处作用，不把情绪曲线设成必须照演的路线。
3. **写出实际呈现。**交付受众实际看见、听见、读到的文字、动作或图像要求，说明哪些已有细节产生体验。线索再写支持哪项认识或调查，互动材料再写支持哪种选择。纯氛围或情感材料可只说明体验作用。
4. **核条件与证明。**明确呈现何时成立、信息从何而来、关键对象和比较字段怎样辨认，以及材料证明到哪一步。区分观察、人物说法与解释；保留尚未排除的说法和未知范围。
5. **检查改变后的反馈。**互动作品分别走查通常接触、提前理解或有效干预，以及未接触或改变条件。说明真实成功保留什么、取消了什么、尚有什么独立原因造成的风险。L1 则检查作者安排的行为与后果是否连贯。
6. **审核实际稿并登记。**按下节分工读取呈现文本和相关材料组合，实改问题后复核。完成时有当前产物、问题处理、采用状态和未验证范围，而非只有主题口号或负面词频统计。

## 证据、条件与变更边界

神秘和未知可以来自已有异常、有限来源或尚不能闭合的机制解释。关键字段仍应清楚可辨，或有合理的辨认入口；不能仅为制造神秘而无理由扣住判断所需信息。来源可追溯，证明范围明确，难懂的文字本身不增加推理价值。

恐惧、伤害和破坏依赖已经建立的世界事实、实际危机及真实后果。呈现可以突出这些事实，却不能凭形容词增加危险、损害或机制权限。人物的真实善意和复杂动机也按已有依据保留。

成功保护、提前识破或停止操作后，按实际条件兑现结果。已取消的危害不补演，已取得的材料不收回；仍有危险时指出独立成立的原因和反应机会。局部成功不保证永久安全，但负面气氛也不是追加惩罚或强制死亡的依据。

区分两种修改：

- **呈现修改：**世界事实、来源、条件和证明范围不变，调整措辞、视听重点、顺序或查阅方式。同步受影响的呈现与玩家材料，并复核辨认和知情边界。
- **上游修改：**建议改变历史、来源、物件、人物知情、机制或风险条件。列出原事实、候选差异、理由与影响；按现有授权处理，同步相关上游和下游对象，再审核新版本。尚未采用的建议保留为候选。

本规范的迁移或验收不自动采用旧 P4 包中的主题建议，也不让它们继承 R3 的采用结论。具体作品的采用、文本检查、纸面走查、实际运行与真人效果各自登记。

## 最小记录与四席检查

把以下字段放入已有目标、线索或场景记录即可。同一对象引用已有事实，不必为每条线索另建完整档案。

| 字段 | 最少写清什么 |
|---|---|
| 对象与状态 | 版本、目标／线索／场景标识，已定事实、采纳和待核范围 |
| 主题与体验作用 | 主题问题、所选题材倾向，本处作用及其所在剧情线／场景／推理阶段 |
| 实际呈现 | 可读、可见或可听的内容，接触入口，产生体验的具体已有细节 |
| 条件与证明 | 成立前件、信息来源、可辨字段、支持的判断及仍未知部分；非调查对象说明适用范围 |
| 行动与后果 | 互动作品可做什么，干预或取消后的持续结果；L1 记实际安排的行为后果 |
| 中性对照 | 哪段保持平实、善意或恢复，怎样与重点呈现共同组织体验 |
| 修改与验证 | 呈现修改或上游差异、权限、实际审查结果、未执行的验证 |

四席是检查职责。按用户约定安排实际审核人员；单人分次自查如实记为作者检查，多个真实独立审核者才登记独立分席。普通局部修订可采用相关检查，完整委员会任务则覆盖四项。

| 检查职责 | 读取与判断 | 应交证据 |
|---|---|---|
| 游玩席 | 实际呈现、活动和可选行为是否形成情绪起伏与行动空间；对照、恢复及成功反馈是否有效 | 具体段落、通常与偏离情形、体验或选择问题；L1 改查受众体验与节奏 |
| 推理席 | 材料组合是否可辨、来源可追、证明范围正确；神秘是否掩盖关键字段 | 支持／不足之处、竞争解释和待核边界；无调查承诺时说明不适用 |
| 剧情席 | 主题是否由行为和后果表达，人物是否仍有真实目的与复杂性 | 人物行动及主题作用的文本位置，候选修法 |
| 可操作性席 | 谁在何时呈现什么，哪些前件成立，改变条件后如何反馈 | 主持／系统可查的条件与反馈；L1 改查对应媒介的可读或可演依据 |

验收对象是具体场景、线索组合和呈现文本。不能用负面词汇出现率或“每条都含恐惧”认定完成。通过条件是本轮承诺产物齐备、适用问题已处理、固定事实和有效成果保留、候选与待核清楚；纸面通过不替代主持、引擎、排演或真人验证。

## 短完整示例：虚构旧展亭的水印

以下是独立虚构例，与任何现有项目无关。用于 L2/L3 的场景候选演示，不是现实规则、真实测试或已采用作品。

**基线与目标。**一座旧展亭没有现实坐标。夜间，钟声响起且桌灯亮着时，桌面会出现新水印，可能洇湿桌上的纸张；关灯后停止产生新水印，已有水印仍在。管理员知道开关位置并愿意告知。当前没有其他危险，也未解释异常起源。这些仅是本例明确设定。

题材倾向选择轻度神秘，主题问题是“面对不了解的现象，人仍能保护眼前的东西吗？”调查目标是辨认本处触发条件并找到局部处理办法，不承诺解释异常起源。

**材料与呈现。**入口处先见一张普通整理单，写明桌灯和钟声的检查记录：两次夜间“钟响、灯亮”记录有新水印，一次“钟响、灯灭”记录无新水印。记录署名为管理员；玩家可询问其观察范围。该整理单保持平实，既是材料，也是日常劳动的对照。

条件成立时，现场文字可写：“钟声落下，桌灯映出木面上的一道湿线。湿线慢慢靠近纸张的边缘。管理员指了指门旁：‘开关在那里。要先把纸拿开吗？’”呈现突出已有水印与可见变化，不增加怪物、伤亡或隐藏惩罚。条件未成立时，只呈现当前灯、纸张和旧水印，不能补演新的湿线。

**证明与行动。**整理单支持灯光与本处水印有关的判断，仍是一人来源的有限记录，不能独自证明所有地点、所有时段或异常起源。当前观察与关灯反馈可用于局部核查。玩家可以取走纸张、关灯、询问或继续观察；继续观察时只按已定条件处理纸张洇湿，不增加题外风险。

玩家提前关灯，即使没等到显影，也停止本次新水印；取走纸张则保住这些纸张。停止后反馈为“木面不再出现新湿线，旧水印仍在”，并保留已经取得的记录。恢复段可以写管理员和调查员一起整理干燥纸张，保持真实合作与平实语气，不再加灾难找回神秘感。

**四项纸面检查。**游玩检查能找到观察、保护与停止的选择及平实恢复；推理检查能分清单一来源、局部反馈和起源未知；剧情检查看到管理员实际帮助及保护行动的主题作用；可操作性检查能按夜间、钟声、灯状态决定是否显影，并结算关灯或移纸结果。本例只展示怎样记录，尚未执行独立分席、主持或真人测试，不宣称实际效果已通过。
