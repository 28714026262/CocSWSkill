# 连续性、授权、版本与技能维护

职责：长期项目及本技能维护。状态轴见[scope](scope.md)，审核资格见[review](review.md)，字段见[contracts](contracts.md)。

## 恢复工作与协作

开始恢复项目权威入口、主动版本、最新用户决定、当前任务和开放接口；阅读顺序服从项目。旧稿追溯，不反向覆盖新决定。读不到材料标缺口，不据此断言作品没有该内容。

先给可读推荐与理由，再列真正影响方向的选择；这是本用户偏好，可按其他用户习惯调整。小细节由作者在范围内解决，未定项集中登记。逐条讨论守住当前问题；整轮授权则完成范围内研究、筛选、实写、修订、复核与交付。授权持续有效，不重复询问已授权动作；也不从“继续”推定安装、发布或改未经授权的固定事实。

讨论、候选落盘、采用、并入母版、冻结各自登记。并入后同步故事、人物、机制、推理、空间与阅读材料，保留旧案和未提交内容。确定新版本还是原版增量按现有约定处理，缺约定时选可回溯的最小改法。

## 事实与变更

原资料的同字母标签可能不同义，按[scope四轴](scope.md)重述材料角色、采纳、事实约束与验证记录。确认事实是项目基线资格，候选／撤回是采纳信息，待核／待验证是验证信息；已有采纳与旧对象的验证证据同时保留。来源场面、关系素材或待核载体不因好用自动升级历史。跨线采用前双向核当时的目标、知情、能力、心理与关系阶段。

先调整呈现和回收，确需改固定事实时列原位置、原事实、建议、理由、影响与不采纳替代，按授权范围执行。不能为保一个素材扭曲人物或提前传知识。作品母版阶段重点是事件因果、职能、立场、知情和关系；具体时代、规则和工程按可行性需求核验，不把所有细节阻塞化。

## 联查与交接

| 改动 | 至少检查 |
|---|---|
| 年代／年龄 | 年龄、亲属、职业资历、事件先后、信件对象、目击资格 |
| 人物认知／关系 | 消息来源时间、信任与误解、披露、合作、离屏与响应 |
| 路线／位置 | 可达、视听、时间、人手、搬运、证据接触、场景出口 |
| 载体／事件 | 来源、保存、公开、推论、冗余、取消后痕迹与结局 |
| 机制／资源 | 依赖、互斥、范围、消耗、补救、手册与已成立保护 |
| 体验组织／表达 | 保留情节、粒度、知情、主稿与附件的一致性 |

停点保留最小当前摘要：阶段、版本、资格、最新决定、开放问题、下一步和路径；历史另供追溯，不让层层追加混淆当前。名称与资产ID统一，变更列影响并同步；必要时记录文件指纹和提交，不以哈希替代语义检查。

## 单一归属与来源状态

运行入口是[SKILL.md](../SKILL.md)，运行方法在本references目录；本技能正文自包含。九来源原文仍保留其用途，不自动退役。迁移审计在[audit/source-map.md](../audit/source-map.md)及[audit/source-manifest.json](../audit/source-manifest.json)，它们不是创作必读。

新经验先判适用层、任务、职责和稳定性，再改唯一归属。不要另建同义定义、重复分类或补充规则堆。项目事实和个人配置外置到具体项目；研究模型标待验证或可选；本轮分流／媒介转译是编辑性适配，未声称外部理论认证。

修改源目录时运行 `python scripts/validate_package.py --check-sources`（路径相对于技能目录）。校验指纹变化后读差异，判断迁入何处、影响哪些产物和用例；语义处理与独立验收之后再登记新来源指纹，不能更新哈希遮住未处理差异。离开原仓库仍可用技能，来源检查需用 `--source-root` 指向真实旧目录。

更新技能：读当前定义→最小实改→同步来源映射→链接／结构检查→重跑受影响行为→独立复核（若本轮要求）→记录新对象与资格。旧报告保留，实改不继承分。安装包若日后另行创建，应作为部署副本，从此源目录同步，不双向维护；本轮没有安装或发布。

## 辅助技能维护

协同选择与交接以[skill-integration](skill-integration.md)为入口，不将个人安装目录作为本包运行依赖。其他会话技能证据与本轮读取对象登记在audit/skill-session-evidence.json及audit/skill-sources.json，和原九份通用来源清单分开；取样未确认使用不等于没有使用。源技能版本变化先读受影响部分、核适用及冲突，再更新实际转译与专项交接，不只更新指纹。同步唯一归属及受影响实际用例，建立新对象验收；旧审核保留其对象资格。

## 新理论与扩展

需要直接引用原作、判断时代事实、医学工程或COC规则时按实际问题核可信原始来源。保存原文事实、可迁移结构与不适用条件，避免二手总结冒称权威原话。素材研究量不等于可用方案数。

本技能结构／语义迁移／AI行为测试各有独立资格；不能给原研究、具体剧本、真人桌测或跨项目有效性补认证。扩大能力声明前用相应真实任务验证并登记范围，修订优先纠正已观察缺陷。
