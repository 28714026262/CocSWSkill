# 调查与推理：材料、证明、认知和行动

职责：证明、线索与认知章程用于有调查目标的L2/L3；一般悬疑剧本可借用公平呈现与证明分析。“七类推理／行动联系”与“由联系到游玩”可按需用于其他互动任务，只读取相关局部节。人物知情在[interactive](interactive.md)，阶段编制在[workflow](workflow.md)。

## 四层分离中的推理层

先分清正在写哪一层，再检查各层如何连接：

| 层 | 回答的问题 |
|---|---|
| 故事 | 实际发生什么，人物为何行动？ |
| 推理 | 受众或玩家通过什么知道这些事？ |
| 异常 | 存在哪些可操作的规律？ |
| 恐怖呈现 | 受众或玩家实际感知什么？ |

各层连接要有因果来源。幕后心理可以写在作者资料；进入玩家判断时，还须有实际可得的材料。后台真相、神秘学术语或全知叙述都不能替代信息取得过程。

关键结论之前，先呈现观察、信息来源和推论过程。NPC 可能隐瞒、说谎或误判；有相应知情依据的 NPC 或档案，也可以直接提供局部事实。

检查一份材料是否过度包办身份、年表、动机、异常与解法。按实际问题分配证明工作，口述和文件都可使用；不设每份文件最多包含几项关键信息的通用上限。

把“玩家理解了”落实为实际认知动作。按当前问题选用以下活动：

- 比较并排除近邻解释，即同样能解释现象的其他合理说法。
- 用可取得的时点重建时间线，排列现场与动作先后。
- 对应物件、痕迹、位置与人物。
- 重构承诺、债务、亲缘、利益与权力关系。
- 让文件、照片、口供与物证交叉鉴证。
- 提出可观察的预测，再选择验证或证伪。

每项交代玩家所需材料、可比较的差异和结论限度。例如，要排除“物件是后来移入”的解释，就需给可比较的时间或痕迹，而不只是作者后台的一张时间图。人物卡也须转为实际材料，才能供玩家判断。

当前问题只需采用相关活动。主动实验保留为可选路径，基础推进仍可由探索、交谈、目睹和目标行动成立。

## 证明责任与否定

对每个结论写清材料证明到哪一步：只提示方向，支持某种判断，足以排除竞争解释，还是已足以据此操作？这些范围按实际问题判断，不靠标签自动升级。

物件被移动、某人实施、存在恶意和多人共谋是不同结论，分别检查依据。旧案责任不能独自证明当前行为，公开职务接触也不能独自证明秘密协作。反驳一种解释后，其他人格判断和异常规律仍需各自依据。

重要传闻记录最初来源、传播者、哪些内容为直接见闻，以及有何独立互证。多份口供、报道或重复答复若来自同一来源，仍是同一事实依据；它们可以另行证明消息怎样传播、谁曾接触消息。

专业经验可以提供有条件的建议。涉及暗道、隐秘事实或安全结论时，仍写明实际知识来源和适用范围。

要用“没有发现”支持否定结论，先说明：若对象存在会留下什么痕迹，实际检查了哪里，以及痕迹能否保存、能否观察。检定失败或一次未找到，只能记录本次检查结果。

误区可以部分正确，拥有真实依据，也可能曾帮助玩家。再用与其证明范围相称的反证揭示边界；误区数量和误判后的回报按作品需要设计，回报也不必是物资。

## 线索作用与最低充分集

线索可从核心、辅助、误导、跨阶段、操作和失败替代载体等作用观察。同一材料可承担多种作用，分类用于找推进缺口，数量另按实际风险判断。

设计时分别检查：核心信息是否有替代切口；误导材料是否真实但解释不完整；跨阶段材料能否早见后重估；操作材料能否帮助改变现实。材料损毁、人物拒绝或检定失败后，保留相应的最低推进渠道，仍按实际损失处理知识范围。

重要性按材料对目标真相、证明或最低推进的作用判断，与取得难度分别记录。容易得到的信息也可能关键，难取得的材料不因此更重要或更有证明力；取得难度描述接近、条件、成本或不确定性。替代与冗余按推进风险配置，不把高难检定当作核心信息必须经历的门槛。

“最低充分集”指支持当前关键推论所需的材料组合。对每个关键推论列出：

1. 必要前件及可替代证据。
2. 组合后的证明限度，以及还未排除什么。
3. 可观察的预测和能证伪它的结果。
4. 只掌握部分知识时，仍可采取的行动。

完成时应能沿材料组合复述推论，并找到失败后仍可推进的实际切口。按核心推进风险配置独立路径；物证、行为和环境历史可提示来源多样性，三条材料或三种类别本身不保证逻辑充分。

## 认知阶段与信息释放

按作用组织信息阶段，例如引出问题、提出竞争解释、局部验证、跨线互证、理解关键真相与行动。阶段可随作品调整。

每条线在当前阶段记录三组内容：已经知道什么、仍缺什么；可以合理怀疑什么、哪些结论还无充分根据；下一层信息或事件需要哪些前件、KP 通过什么可观察变化判断推进。

每线索注明正常、主动调查、追加公开的条件及冗余来源。真实可达性、人物信任和实际知情、载体变化、必要比对与呈现层次可以控制释放；物件存在与意义被理解分别记录。

检查阶段累计组合与跨线组合是否无意提前给足答案或到后期仍缺前件。公开事实已足够时承认提前识破，调整行动与后果，不临时改真相、扣住已取得材料或要求念出标准答案。NPC行动可独立发展，不都等待解谜。

## 七类推理／行动联系

<a id="seven-links"></a>

七类是源方法的操作分类，分类帮助找缺口，不作为每线配额：

局部适用：A1—A4可服务非调查互动的合作、任务与状态联系；R类在确有信息、探索或解释需求时采用。调用本节不意味着必须编证明章程或最低充分集；一般叙事／主题并置可直接使用narrative的分析视角。

| 类别 | 作用 | 边界 |
|---|---|---|
| R1 线索提供 | 增加信息、重估旧事实、改变解释 | 来自实际事物与行为反馈，有来源和证明范围 |
| R2 探索导向 | 指向人、地点、物件或事件 | 给理由与接近切口，不指定唯一任务顺序 |
| R3 猜想筛选与收束 | 核竞争解释、缩范围、汇核心问题 | 正当有限排除，收束理解而非固定结局，可有未知 |
| A1 人际关系影响 | 改变合作、保护、隐瞒、控制等 | 按人物立场回应，不以查完故事自动发好感 |
| A2 行动关联与条件改变 | 协作、争夺、阻碍与机会 | 具体到人手、材料、路线、独处等，不混同是否知道 |
| A3 行动指导 | 提供可用经验、方法与风险切口 | 支持决定，不给强制解题口令 |
| A4 世界状态与事件进展 | 获得、转移、消耗、修复物件及改变路线事件 | 持续结算促成、阻止、延迟和取消，不强迫升级全局危机 |

同一联系可有多个作用，仍是同一联系。A2是行为互相影响，A3是如何知道可做什么，A4是实际留下什么变化。生活接触、合作、条件变化不新增第八类；旧十机制不重复计数。

## 由联系到游玩

先把联系写成一条可追踪的过程：来源事实或行为→受影响故事线的反应或解释→玩家可感知表现→接触或介入→持续结果。注明必要前提及事实状态。

再检查玩家接触并介入、未接触、采用其他合理方式三种情形。完成时应能说明各自可见什么、能做什么、留下什么结果。主线对支线的反向压力、弱联系和人物独立欲望也一并保留。

理解可增加交易、操作、准备和风险识别；行动反馈可回到推理，允许行动先于全解。不把大量听背景而无法行动，或大量操作但不知意义当作丰富度。基础推进不依赖唯一NPC、单骰或全查支线，深入操作可以获得额外优势。纯情感小线不强求推理／行动循环。
