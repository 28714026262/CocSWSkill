# 审核、独立验收、测试与收束

职责：验证方法；按当前阶段与承诺评价，不能给未执行验证补资格。返修路径见[workflow](workflow.md)。

## 先确定审核对象

记录版本、文件、阶段、实际读稿范围、评审者身份和参与编写关系。作者解释不能补正文；冷读先不读母版或其他意见，再按需要核连续性。若阶段要求独立验收，验收者未编写该步产物，必须实际读稿并写证据，未通过实改、复验后才进入下一步。

多席按需要分剧情／人物、推理、玩家／KP、时代技术等职责。单代理分次检查如实称作者检查；多个真实独立AI代理称独立AI审读，不冒称真人委员会。复杂任务可按用户安排独立或并行，小修改不强制多席。没有独立工具时明示未完成独立验收，不能模拟席位包装通过。

评分是诊断结果：问题要有文本位置、事实、影响、成因、修法与复核标准。先诊断故事缺口、人物、推理、行动、节奏或表达。门槛与量表按项目；各关键维度单独看，不以平均分、多数票抵消硬矛盾。新稿、合成稿和审核后改稿不能自动继承旧分。

## 阶段校准

| 对象 | 当前重点 | 不据此自动失败 |
|---|---|---|
| 素材／候选 | 需求契合、可发展性、风险和边界 | 尚未成完整故事或场景，只要状态正确 |
| 大纲／母版 | 主题、动机、因果、知情、推理潜力、选择与后果 | 未定具体手证、房间尺寸、数值；但核心可行性风险须核 |
| 体验上限稿 | 实际发展、冲突、亮点、视角来源、可读性及开发价值 | 尚未全量实施玩法；KP辅助高分不能代替主稿 |
| 施工样段 | 位置、动作机会、载体、检定、状态和偏离响应 | 未承诺覆盖的全剧本资产 |
| 可运行包 | 自包含、查阅、统一裁定、结局与资产一致 | 不必穷尽一切玩家行为，未测项要明示 |
| 桌测复盘 | 真实行动、理解、停滞、负担、干预、KP补充 | 不拿作者预期代替测试记录 |

## 十二项评价框架

这些维度按作品承诺启用；不强加封闭、生存、固定证据／误区数或收费结局。

一般非互动作品核受众理解、人物行动与可演／可见呈现，不用玩家选择或主持门槛评价；数字互动核条件、状态与接口，文本走查和引擎运行分记。阶段输入与完成标准优先采用workflow的媒介覆盖；非调查目标无需证明链，纯氛围无需转为推理工具。

| 维度 | 核验问题 |
|---|---|
| 故事与主题 | 人物与人类冲突能否独立解释；主题是否由行为和后果表达 |
| 背景可信度 | 时代、生活与重点背景是否相称，知识入口和现实／虚构边界是否清楚 |
| 人物主体性 | 不介入时会做什么，关系与诉求是否不同，揭晓后是否仍有动作 |
| 推理公平与误区 | 材料是否先于结论、支持范围明确、竞争解释可比较且可修正 |
| 反转交集与爆点 | 是否重估旧事实，交集改变局势，揭晓后有选择与执行余波 |
| 生存与威胁 | 若承担压力，发展、预警、窗口、工具与干预成果是否成立 |
| 探索与恐怖 | 空间与异常可接触、重点区体验有差异，纯氛围或操作作用合适 |
| 玩家主体性 | 判断和行为能否影响合作、路线、代价、成果或结局 |
| 机制融合 | 规律及执行负担是否相称，调查／生存／行动接口是否连续 |
| 节奏信息负担 | 高潮与静水、急缓、并发、术语和前景人物是否按人数承载 |
| 结局与余韵 | 回应开场与主题，取舍有实际依据，局部成果保留，无强制道德判词 |
| 主持与扩展 | 入口对象反馈出口可查，偏离有依据，模板适合继续施工 |

## 悬疑专项审核与修订层级

有悬疑承诺时借mystery-payoff-and-fairness-judge检查：承诺与开放问题、揭晓前实际材料及误读、已有动机／信息／能力、认识／压力／关系／代价的变化，揭晓怎样重估旧事实，干预成果怎样继续改变后续选项。按十二项框架相应维度记录，不另建第二套通用量表；派系、诡异操作功能或逐章升级只在该作品有此承诺时检查，纯氛围不因此失败。

修法先定位语言、场景、跨场发展或整体机制哪一层：优先处理因果与人物能力矛盾、证明缺口及被抹去的成果，再处理信息阶梯、节奏和表达。材料不足以排除竞争解释就保留未知；复杂、晦涩和审核高分不替代公平证据。说明支持判断的实际段落与残余风险，修改建议不自动成为已采用事实。

源悬疑量表1—5与本项目其他量表不能无依据换算；评分可选，启用时写所用版本、适用项、尺度与证据，不把历史9.2等项目门槛设为通用合格线。人物结构冷读先让未编写者凭实际阅读稿理解动机、事件和体验，再联查后台事实；作者补讲或保留旧上下文的试用分别登记，不能称全新冷读。专用技能选择见[技能协同](skill-integration.md)。

## 定点测试

先逐线再全局：需求、故事因果、接触理解、动作、跨线影响、持续回收。再做删除（事件／理解／关系／情感）、重复、证明、知情、能动性、节奏与负担检查。

按任务选择反例：正常路线、错过入口、取消前件、提前识破、漏房／漏线索、损毁证物、人物拒绝／离场／死亡、救下原定受害者、单人受伤、分队、错误解释、只求自保、提前撤离与其他合法结尾。

额外接口检查：沙盒拒可选引入；秘密成功且断监视；同证据给不同NPC；强盟友在场与离场；节点重复使用；不了解背景／误读暗示；破坏依赖后补救；两角色错时触发、延长或取消时钟；跨章节查同机制。记录可见、可做、反馈和是否临时补事实。

## 验证资格

- 文本检查／独立AI审读：检测表达、因果、证明与接口，只证明明确对象的文本结论。
- 纸面反例／AI模拟：可推演状态，不等同真人体验或实际主持。
- 非作者KP冷读／运行：凭包准备、查阅和裁定，记所需作者补充与偏离处理。
- 真人桌测：记实际行为、理论、信息接触、停滞时长、NPC抢镜、资源依据、成果与结局；不先解释答案再问“是否理解”。
- 媒介运行：一般剧本的朗读／排演或数字游戏引擎运行按实际安排登记，不从AI评审继承。

标准／短版／单人等规格分别写差异和实际覆盖。结构校验、文字复述、模拟、冷读、真人各有作用而不互代。问题可分阻断、明显体验、表达制作、扩展想法；阶段决定严重程度，必要因果缺口不按润色处理。

## 停止与复测

<a id="stop"></a>

达本轮目标、无必须修复问题且收益收束就停止加料；普通建议留后续，不无限循环自由扩写。未达标时承认未通过，指出结构或必要输入；相同小修反复无效就换结构，不抬分或更名。复测覆盖实改影响，不无理由反复重评全部。

用户反馈推翻核心体验或可读性时，登记实际退回，旧高分保留为旧对象历史。修当前主稿后独立核可读、事实与开发价值；全文复核和局部差异检查分别记。母版、技能、阶段稿、成品各自的通过资格独立。
