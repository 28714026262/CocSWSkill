# Q7：八分钟的保管争议

这是一段从10:12开始、围绕原稿Q7展开的调查桌游场景。玩家的即时目标是确定原稿在哪里、保护它，并决定是否允许甲将它带出门；历史责任和完整动机可以留到原稿安全后处理。下列台词和手证只呈现题设事实；耗时、公开顺序、记录载体及人物回应是本稿的运行安排，不新增秘密人物、替换稿、交易条件或隐藏目的。

## 开场与桌面材料

主持读出：“10:12，你们进了小展厅。展台上没有原稿Q7。展台、保管柜和门口是你们可以调查、交涉或守候的位置。你们可以一起行动，也可以分头。”不要在开场直接宣布盗窃，也不要把10:10的漏水写成现在仍然发生。

摆一张时钟卡，正面写“现在10:12”，不预印10:20的用途。每次玩家完成一个普通检查或一轮针对同一问题的问答，推进一分钟；简短报信、提出保护要求、转交已有材料不另收费。同一时段的分头行动并行计算。耗时是可调整的桌游规则，不是历史证据；宣布耗时后再执行行动。玩家改变保管条件后，允许暂停紧张计时、继续讨论责任，不能因历史未查完而重启交货事件。

以下六张信息卡是可直接使用的材料。信息交给实际接触者；私下取得的卡先放在该玩家面前，只有分享后才移至公共区。主持不把个别玩家的所知默认为全队所知。

| 卡 | 实际呈现、取得方式与来源 | 能证明什么、不能证明什么 |
|---|---|---|
| A 门卫口述 | 向门卫询问Q7去向，他答：“甲跟我说过：‘我收进柜了。’我知道的是他说了这句话。” | 可把调查引向柜及甲；只证明甲作此陈述。门卫没有独立见证移动，不能与甲同一句话算两份独立互证。 |
| B 柜内观察 | 乙通常愿意开柜。玩家提出确认原稿或保护原稿，乙开柜让其查看。交卡：“柜中有稿件，眼下干燥。” | 直接确认柜内稿件及当前状态。不能独自证明这就是展台原稿Q7、10:10为何移动，或纸张以前是否受水。题设未提供可供鉴别的独有标记，不临时补出笔迹暗号。 |
| C 乙的历史见证 | 向乙问“你亲眼看到了什么，时间是什么”，通常答：“10:00，我亲自记下原稿Q7在展台。10:10，我连续看着甲把同一稿从展台移进保管柜。当时展台正在漏水。”交完整原话卡。 | 将时点、执行者、物件同一性和现场条件连起来。依赖乙这一个历史见证来源；足以在本场景中确认移动事实，不能自动证明甲只有救稿动机。 |
| D 旧任务登记 | 作为可损失的手证载体，文字仅为：“旧任务授权：展台→保管柜。出门：须乙另准。”玩家主动查阅旧任务范围可取得；若此前已失去，不重新补发。 | 提供权限范围；不证明甲实际执行过什么，也不证明乙现在批准了出门。它不另记10:10经过，不给历史见证补造独立副本。 |
| E 乙的当前答复 | 问“眼下是否准许甲带Q7出门”，乙答：“现在尚未批准。”若同时问旧任务范围，答：“旧任务只授权从展台移进柜；出门要我另准。”交卡。乙拒讲历史时仍可回答这个当前处置问题。 | 与D或乙的任务范围答复组合，可确认当前无出门许可。乙讲自己的授权及当前批准状态，来源与权限相称；拒讲历史不等于拒绝所有合作。 |
| F 甲的交货准备 | 玩家问“下一步准备做什么、什么时候、到哪里”，甲答：“我准备10:20向门外交货。”不要替他补买主、价格或目的。未问到时，10:20甲开始实施该准备，形成当面可干预事件。 | 提前提供风险窗口；陈述计划不等于已经出门。10:20实际动作可替代这张计划口述卡，用于判断眼前行为；动作不能反向证明此前的全部动机。 |

甲若被问“是不是为了救稿”，主持可答“当时展台漏水”或让甲不回答目的；不要把这种答复升级为唯一动机。若问材料未交代的目的、交易细节或同谋，答“现有材料无法确定”，而不即兴创造答案。乙拒讲历史是本稿明确保留的失去信息路径；拒绝不会撤销玩家已取得的历史卡。

## 四个认识阶段

阶段按玩家实际所知判定，允许越级，也允许不同玩家停在不同阶段。把玩家做出的判断及所用卡记在桌面上即可，不要求他们念出标准答案。

| 阶段与实际问题 | 充分依据及替代依据 | 玩家怎样推进，主持怎样确认 |
|---|---|---|
| 1 去向不明：“从展台消失”是否就是被盗？ | 开场只能支持“展台已空”。A支持查柜；B足以确认柜里有干燥稿件。A与B仍不足以独立确认历史同一性或盗窃。 | 查柜、问门卫、问甲均可打开行动。玩家提出“先确保柜内这份不被带走”就是有效的保护决定，不需要先证明它是Q7。主持落实实际可行的保管安排，承认其收益。 |
| 2 历史移动已确认：“甲移动了哪份稿，何时，处境是什么？” | C中连续目击连接同一稿、甲、展台和柜，另含10:00及10:10时点。结合B确认现在柜中状态。C是历史同一性的充分来源；A、B或干燥状态没有同等替代效力。 | 玩家重建“10:00在展台→10:10甲移入柜、当时漏水→10:12柜内干燥”。合理收束为“甲确实移稿，移入柜有保护价值且符合旧任务范围”，其中任务符合还需D/E。不能推出“甲只想保护”或“甲此前就是盗窃”。 |
| 3 权限与风险分开：“哪些行动已有权限，下一步能否出门？” | D＋E确认旧任务止于柜、当前无另准；D遗失时，E中乙对旧任务范围及当前批准状态的直接答复是替代依据。再加F可确认尚未获准的出门计划。没取得F时，可先设定保管边界，10:20用甲实际企图将稿带向门外的动作补足当前风险。 | 玩家明确区分已经发生的柜内移动与尚未发生的出门行为，决定核验许可、暂缓交货或守住稿件。主持将其安排落实到人物或物件，不以未解释甲的目的为理由拖延。 |
| 4 有限结论与行动结算：“现在能够指认什么，仍不能指认什么？” | C＋D/E支持历史移动在旧任务范围内；D/E＋F支持当前交货准备尚无出门许可。若甲在未获批准状态下实际出门，才形成实际越过权限边界的行为。完整动机没有充分集。 | 保护成功、未准出门被阻止、历史仍未知、动机仍未知可以同时成立。玩家可以提交有限报告：“保管已确保；历史移入柜可确认／尚无法确认；交货计划未获准；恶意及全部目的未定。”不用查出全部目的才算结束。 |

两个主要竞争解释直接交给玩家比较：“柜里现在是干的，所以当时一定没有漏水”与“甲将它移走，所以一定是盗窃”。前者不能由现在状态倒推过去；C提供真实的历史条件。后者把物件移动、任务权限与心理目的合并了；D/E使玩家能够拆开这三件事。相反，“漏水说明甲完全无私”也越过了材料范围。支持保护价值的事实，既不洗清全部目的，也不证明恶意。

## 主动查法与事件反馈

**对时并追问见闻。** 玩家让乙把10:00、10:10、10:12排在桌上，追问“中间是否连续看到同一稿”。按C逐句答复；让玩家亲手把“门卫听说”放在另一列。收益是辨别直接见证与转述，不再产生第三个隐藏时间点。若乙拒讲历史，本查法失败的是历史取得，不是“历史移动不存在”。

**开柜检验当前命题。** 玩家预测“柜里有稿件且眼下干燥”，乙开柜后直接给B，无需用失败骰否定固定事实。观察支持当前命题；想检验“从未漏水”时，提醒这次观察没有对应的历史检验能力。没有题设支持的纸张损伤、摄像头或暗记，不提供为捷径。

**把权限问题问成可行动的问题。** 玩家分别问乙“旧任务允许什么”“现在准了没有”，获得E；把D旁的“出门须另准”与“尚未批准”对照。可将共同商定的边界口头转告甲、门卫，并确认听到答复。消息只更新实际听到的人；门卫得知批准状态，不因此成为10:10的目击者。

**安排守候或延缓。** 玩家可请乙继续保管，守住柜旁，或让一人到门口提醒核验许可。主持要求把口头建议落实为具体行动：谁在何处、稿件由谁保管、谁知道哪些指示。若乙接受继续保管并阻止取稿，或玩家以可行方式确保甲无法取得稿件，10:20的交货条件已失效；主持宣布该次交货被取消。单纯提出疑虑但没有改变条件，只产生已通知的记录，不凭一句话自动锁死行动。

**当面检验计划。** 保管条件仍允许甲接触稿件时，10:20甲开始按原准备将稿件用于门外交货；先描述可见的取稿及向门外动作，给在场玩家一次完整干预机会，不直接宣布交付完成。玩家可要求乙核准、拦下稿件或让甲停下交涉。此时核对E是否仍有效：若乙在玩家影响下现在另准，记录新批准及时间，原先“尚未批准”的卡仍是当时事实；不能继续把后来的获准出门称为未授权。若仍未准，行动越过门才结算为实际出门。不得因被阻止而补出暗道、替稿或备用交货者。

## 偏离分支

1. **乙拒讲历史。** A仍能引导查柜，B支持保护，D/E支持核查权限，F或10:20动作支持风险判断。玩家可以成功阻止未准出门；历史同一性、10:10漏水和当时动作无法达到C所给的证明程度。主持允许以“当前保管与许可已经处理，历史待核”结束，不把未知写成罪证，也不制造新的目击者补齐损失。

2. **登记损失。** 若D已经给玩家并被记下，其知识保留，原始载体的可提交性损失；若未看过就失去，改问乙取得E。E是对任务权限的直接答复，不是把遗失登记复制出来。若玩家也不问乙，则权限仍未确认，他们仍可请求暂缓交货，但报告必须注明依据不足。

3. **先保护、后调查。** 10:12便开柜并落实乙继续保管，或以可行方式看住原稿，能够提前消除本次出门风险。随后自由问历史、核任务。10:20照时到来但不强制取稿成功、不要求玩家补做动机谜题；已取得的保护成果保留。

4. **分头且未分享。** 一人有C，另一人有D/E，第三人只听过A。各人依自己所知行动；主持允许他们报信、展示卡或约定汇合，分享不额外耗掉整分钟。若不分享，门口玩家可以从自己的E认定当前无许可，却不能宣称自己见证了10:10；柜旁玩家可以确认历史，但若没见许可资料，不能自动知道出门边界。保护可能成功而联合报告暂未形成，照实结算。

5. **提前定罪或完全信任甲。** 以“甲移走＝盗窃”指控时，给已可接触的C、D/E让玩家修正证明范围，人物不因此吐露未设定的秘密。以“漏水＝一切合法”放行时，若获得D/E则让他们看到出门需另准；若坚持不干预且没有改变条件，10:20事件继续。主持不替他们补作核准，也不追认已有许可。

6. **一直追问完整目的，错过行动窗口。** 材料不能回答的目的保持未知；主持用时钟及已取得F提醒实际时间。到10:20按现场条件结算，允许在场者介入。若最终发生未准出门，能确定的是具体行为越过边界；不能顺势补成盗卖阴谋。若原稿已提前安全，则错过这个时点不产生被取消的交货。

## 收束记录

场景结束时只填写四行：原稿／柜内稿件当前在哪里、谁保管；哪些历史事实由谁取得并分享；出门许可在什么时点处于什么状态；10:20计划被取消、延迟、获准实施或未准实施。附上仍未知的同一性或动机问题。当前稿是桌面运行设计，完成文本及条件走查，未进行真人桌测。
