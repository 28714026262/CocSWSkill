# 档案室换箱案：P4内嵌调查KP管理页

身份：固定材料的AI纸面制作；仅为条件设计，非完整可主持案件。来源仅本轮任务；下列简称是本页索引，不增设事实库。谁换箱、唯一真相均未定。

## 进入与当前工作

局部问题是“现有材料支持怎样的换箱判断”。可从甲的声称进入，给出其内容：“我看见乙离开。”这是证词，不是KP确认乙确曾离开或换箱。玩家的参与动机、在场条件尚未给，开场需补；不虚构委托。玩家可以先查门、先公布或不查。此页用途是帮助比较身份、接触与物件用途的证明边界，允许保留未决。

## 按对象取用

|来源|取得与实际内容|比较及限度|
|---|---|---|
|甲|接触其声称时给上述原话；询问入口、视点和后续答法待补|与门登记比较；不能把转述写成确认，也不能断言甲撒谎|
|门登记|查阅条件待补；若取得，只给“下午开门”|不记身份，既不能证实乙，也不能排除乙；无精确时刻可供排时序|
|铰链|亲看可得“新擦痕”；接近条件待补|可与“铰链没有新擦痕”的解释比较；不自带成因、工具、制造者或确切时间，不能认定擦痕来自换箱|
|箱内旧清单|取得箱内阅读机会时给“旧用途”；具体文字、开箱权限待补|与“清单足以说明今物”的解释对读；旧用途不保证今物，不补当前物品|
|乙|可拒答或展示；实际分支及展示对象待补|拒答不证明有罪；展示只按已定内容回应，未定前无可发放的展示证据|

本次取得后记：何人、来源、有限内容、分享给谁；计划可得、相信与证据支持另记。

## 玩家真正比较什么

“乙换箱”与“非乙换箱”目前都不能由上述材料区分；这两项仅是待检解释。先查门可发现登记无法核身份，再自行决定是否核甲的观察条件或问乙；相关决定性答复未定，登记待补，不现场补证。查铰链能取得擦痕，查清单能确认其写旧用途；两项合起来仍不能证明谁换箱，也不能确认今物。不存在现成充分组，不用排除法宣布剩者有罪。

## 提示与偏离

不知如何比时，只针对已得内容问：“登记写了身份吗？”或“旧用途能说明现在装什么吗？”尚未取得的内容不能夹在提示中。材料分散时征得玩家愿意后按实际分享整理；未分享者不自动互知。误认乙有罪时重述证据范围，容许保留猜测。

先公布时记实际公布内容及接收者；未给NPC反应不自行补。乙拒答后，门登记、擦痕和清单最多维持上述有限认识，不能替代口供。材料失去则核已取得记录及真实剩余入口，不空降副本。预设外检查先确认想区分什么，再核已有事实；未定结果登记，不奖励式造证。

## 收束与再入

可在“身份无法核实／今物未确认”处暂收，记录保留材料、继续核查或离开的选择；这些是行动选项，能否执行取决于尚待补的权限。停止或不查均返回主流程，不以认凶开门。再入按当时物件与人物状态续记，已得知识保留。具体主流程后景、耗时、移动与变化触发均未给，不能宣称已安排。
