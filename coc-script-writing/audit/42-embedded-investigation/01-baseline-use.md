# 档案室换箱案：P4内嵌调查管理页（旧方法基线）

范围：局部制作，插入已有P4当前档案室场面。仅读before/SKILL.md、before/references/workflow.md及before/references/inference-design.md旧快照，按8.0/8.1直接使用；未读新增方法、D9及其他评审。此为文稿使用记录，不是实际KP／玩家运行。

进场即允许问甲、查门、查箱或不查，无固定顺序。甲的可给话语只有“我看见乙离开”；这是甲的主张，不是KP确认乙确曾离开。问站位、时刻或辨认依据，现输入未提供，记录待补，不能临场编证言。谁换箱及唯一真相属作者未定，不作为本桥段可揭晓答案。

|查法／信息|KP交付与证明限度|
|---|---|
|读门登记L1|实际可读时给“下午开门”；二手记录，只约束所记开门时间，不给来人身份，也不把没记姓名读成乙没来|
|亲看铰链L2|给“铰链有新擦痕”；一手当前物态，不能推出谁擦、何时换箱或擦痕必由换箱造成|
|读箱内旧清单L3|仅给原有旧用途内容；二手文书，不补具体用途名称，不据此宣布箱中今物|
|问乙L4|乙可拒答或展示；拒答记未获答，不判有罪；展示只结算实际展示内容，不额外附认罪、解释或新历史。展示对象未给，不自行填值|

本段可做的比较G1：“现有材料是否足以确认乙换箱？”玩家把甲说法与L1、L2相接时，指出门登记未识人、擦痕未识行为者；目前没有充分组合，记R4-U而非乙有罪或无罪。G2：“旧清单能否确认今物？”比较文书所指旧用途与当前要确认的对象；没有今物依据，维持未决。回报是把指控和待查分开，帮助选择继续核来源、检查实际可接近对象或有限公开。

每次行动后记：接收者｜取得原文／观察｜玩家判断｜支持限度｜实际公开给谁。先查门立即给可读字段，不等先听甲。先公布时逐项区分“甲声称”“登记记载”“亲眼观察”；消息仅传给实际听到者，不生成NPC回应或案情变化。未分享不汇总角色知识。

停滞可提醒比较“记录的是开门还是人”“清单写的是旧用途还是今物”，不补物证。拒供、未查或玩家退出，保留已得信息与未决；本段结束即可返回原P4下一既有场面，不以破案解锁。额外人物响应、耗时及前后场后果输入未给，标为接口待补，不冒称完整案件可运行。
