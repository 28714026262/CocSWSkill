# 固定条件使用输入：闭馆前的铜像

用户任务：按技能为下列既定事实写一份有限的P4推理桥段。提供事件／观察时间与玩家认识推进的对照、具体线索组合到判断的全过程、可行的调查路径、主持提示和结束分支。正文让KP能读懂实际材料与下一查法。可以补表达与组织，不新增事实、证人、鉴定或当事人承认。研究和外部工具不需要。

背景：小型展馆闭馆时，一尊铜像在库房地面被发现倒下，底座新断。玩家协助保管记录后可自愿查案。作者知道修复员司岚为抢救展柜中的水渍把铜像取出，搬动时摔坏；想隐去自己的失手。仪器员陶简实际检查过另一间房的旧设备，未参与铜像搬动。守库员顾衡没有离开过资料工作点参与本次搬运。世界不存在瞬移，库房作业须离开资料点；没有采用精确通行耗时。

以下为默认可接触的已定材料，均可按合理询问取得，不存在逐字口令。

- 09:01顾衡把常用短扳手还给司岚。记录员林予亲见。扳手是普通类型，无唯一工具鉴定；新底座断口也没有已定的工具归属判断。
- 09:02—09:05林予离开取空白登记纸。绘图员沈砚第一次到资料点，没带平板，只见顾衡；顾衡说林予取纸。这句话不是沈砚亲见林予取纸。
- 林予09:05回工作点，随后至09:12抱已登记页归档一直近距同顾衡逐项读码、相互核对，无可离开一趟的中断。09:07展务员来此请核铜像的旧标签，林予顺门口近距看见库房小推车上的铜像底座外观完整；展务员又把推车推进库房。观察只涉及可见外观，不保证没有任何隐裂。
- 沈砚09:10第二次携平板到，林予仍持旧标签原页，沈砚抄平板下缘，顾衡指同一字码；林予等转抄后才抱原页与已登记页归档。
- 沈砚自第二次到场，与顾衡连续核板、同行到门厅，09:18将板交给讲解员乔葵。乔葵已经同顾衡指板问答时沈砚才离开。乔葵与顾衡持续近距问答，直到09:25库房损坏消息打断。分钟为作者参考，各人主要能说事件先后。
- 有真实的登记纸：“09:01开核；纸不足停；09:05续核；旧标签原页转板下缘；已核页归档。”旧标签原页随林予归档；门厅平板只留下字码转抄，两个是不同物件。纸没有记录铜像断裂时间，也不保证人在场。
- 陶简09:04结束自己在门口的设备清单项后去另一间房；其同事此后未全段见他。旧设备的外盖编号处有擦拭，对照页写“外号已核；内件待复查”，无时间；本人能指出对应部位。没人有整段担保，也没设计其他精确定时物。
- 司岚09:20才首次被乔葵看见在门厅坐下。乔葵其后主要在同顾衡核板，不知道司岚前段行踪，也没有担保司岚坐下后全段。
- 库房地面有擦开的旧灰、铜像旁一块少灰边界和倒地后的金属碎屑。少灰处没有足够特征唯一匹配铜像底座，擦带没有已定方向。展柜内有真实水渍。玩家没有机会看到本次搬动。
- 司岚在被问到库房经过时默认说：“我去时柜已经开了。我把它托到地上。后来展务员回来，我们争执了几句。”没有说明“它”在被托下之前是否完整；问到这一点时他拒绝进一步解释。不会额外承认摔坏。展务员只知道自己此前送回时所见、之后回房看到已经倒地，不知道中间动作。
- 所有人当前仍能接触，但可以拒绝让人扣押私人物品；玩家能提出共同保管残物、暂停后续搬运、公开已知的记录、分人询问及继续闭馆工作。保护成果按是否真实同意和执行处理，查不清不触发额外事故。

若玩家发现消息后请乔葵去帮助收残片，她的先前问答事实保留。若玩家在问答尚未完成前把她调走，按实际时段更新；不要为了保住默认谜题恢复无缝覆盖。以上已给事实和缺口均为本次边界，不能用作者知道的经过补入玩家材料。
