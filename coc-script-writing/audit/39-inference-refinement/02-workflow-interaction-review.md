## 纸面方法输出一：主路线受阻，提前止险后NPC下一步

### 本例采用输入与可知起点

以下仅为本纸面例明确设定，不写入任何项目：

| 输入ID | 确定内容 |
|---|---|
| E01 | 原定入口被损坏门板挡住；挪开须两名空闲、有搬移能力的人共同操作。门板松动是独立已存状态，关供汽不使它修好。 |
| E02 | 调查员已关供汽，新蒸汽伤害真正取消。工人川在场目睹并确认；护士叶在隔室，没有收到停汽消息。 |
| E03 | 川正两手扶住松动门板，目标是避免它倒下；当前可短说，不能自行取物、搬门或离岗。换人扶稳之后才可能腾手。本例没有完成换岗。 |
| E04 | 叶正持续护理伤者，目标是维持已稳定状态；可就眼前照护短答，当前不可离岗、搬移或讲长段私人经历。接班需要具备本例护理能力者实际接手，调查员不具该能力。 |
| E05 | 已有服务走廊可供一个人步行抵达资料室；其门钥匙在入口侧墙钩，调查员可接近。川知道路线和钥匙位置，愿意告知。此处没有新增暗道、人物或钥匙。 |
| E06 | 本例一个调查员尚可自由移动。川曾说愿帮挪门，只是承诺。其他人员没有可供调用的已定输入。 |

调查员已见 E01、关汽与川扶门；知道叶在护理，但没有得到川的路线提示，也未掌握叶的私人往事。作者／主持后台所知不整包转成调查员知识。

### 实际下一步正文与岗位结算

**没人问也会发生。**川见停汽成立后，继续扶门，主动短说：“汽已经停了。先别抽这扇门，我还得扶住。去资料室可以走服务走廊，钥匙在你右侧墙钩。”当场调查员实际听见则记本次收到；若未听取，记发出而不记已知。叶继续护理，既不因玩家没提问而停机，也不凭后台知识宣布停汽或离岗加入搬门。

| 人物／事项 | 当前变化 | 未成立的结果及真实下一条件 |
|---|---|---|
| 川 | 已亲见停汽，取消与新蒸汽有关的警戒；仍扶独立松动门板，主动给既知短方向。 | “愿帮搬”不等已离岗、交班或门已挪开。调查员实际扶稳替岗后川才可能腾手，但此时只有川一人空闲，仍不满足两空闲人搬移。 |
| 叶 | 原照护和已稳定成果延续。收到调查员当面停汽消息后，可记录收到、相信及有限反应，再继续护理。 | 无护理能力接班者，不能把“调查员愿照看”视为护理交班已完成；不会自动提供长供、出劳力或共享停汽消息给全员。 |
| 调查员路线 | 可以选择取已有钥匙、走已有服务走廊、短问、继续寻找已定接班条件或退出。 | 不能凭川的指路直接记已取钥匙／抵达资料室／读完资料；也不能为恢复原主路线临时刷新劳力。 |
| 止险成果 | 新蒸汽不再产生相应伤害，既有状态和已得知识保留。 | 门板风险按 E01 原因保留；不是重新添事故收取止险代价。 |

短提示是人物按目标、知情及能力的主动行动，不是玩家必须问中口令才能启动。主路线当前继续受阻是人手与岗位限制，不是角色不够积极；服务路线依既有事实可行，也不保证调查员选择它。剧情下一段可转为取得资料、协调岗位或撤离，游戏进度不要求先完成某个旧案推理目标。

**公开与证明。**扶门及关汽后的当前可见状态是调查员直接观察；川的路线说法与叶的答复是人物二手内容，原知资格分别记录。见川还在扶门可取得该局部事实，不需要先完成换岗；听见他承诺只取得承诺，不发已经交班或门已经开放。调查员尚未取得资料室内容，不能把新方向计为支线成功。

**本例停点。**已产出无人问时下一步、有限答复、岗位及半链条件、仍阻主路的原因与可行选择。本纸面输出不往后假定成功，不虚构护理数值或门板真实工程参数；应用到具体作品时，决定性物性和裁定须有该项目依据。
