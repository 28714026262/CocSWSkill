## Q1 固定数字过场

**守卫：**“对不起。”

**船主：**“但我没有原谅你。”

**守卫：**“我明白。”

**船主：**“今晚继续值夜。”

守卫迟疑了一下。

**守卫：**“你还让我值夜？”

**船主：**“让你留下，不等于原谅。”

## Q3 非调查数字文案交付包

实际加载：SKILL、scope、workflow、interactive、contracts、craft、review。数字L2，承诺为文案和节点接口。母版按题目固定，未附此前验收证据，不虚称母版已经独立通过。

玩家在同一码头看见老人和推车工。老人希望搬两箱货，推车工能完成搬运；玩家可以帮忙，也可以拒绝。接受时玩家实际搬完两箱；拒绝时推车工照常搬完。货物完成后老人离开，帮助只改变老人对玩家的态度。整个任务没有调查谜题、时间危机或物质奖励。

### 本轮采用的阶段

| 对应阶段 | 本轮完成的产物／适配 |
|---|---|
| 前置恢复 | 固定人物、同一码头、两箱可搬、选择起点与终点，不重新造母版 |
| 1代表体验 | 接受与拒绝两条短路线；主要体验是是否承担劳动及态度反馈 |
| 2因果条件 | 接受→玩家搬运；拒绝→推车工搬运；都汇入已完成后的离开 |
| 3世界状态 | 两箱逐箱完成，完成不可逆；老人是否离开与实际帮助独立记录 |
| 4事件／信息进程 | 邀请→选择→搬运→反馈离开；不编谜底证明或推理分册 |
| 5场景接口 | 下列玩家文本、节点读写与重复保护 |
| 6工具收束 | 状态定义与终止条件；不做COC数值、KP手册或引擎代码 |
| 7纸面走查 | 核接受、拒绝、分支汇合与重复，不记引擎／真人通过 |
| 8文本交付 | 同一节点ID、文案及状态接口包；实现细节由实现者处理 |

### 玩家可见文案

**N0 开场：**码头上，老人站在两箱货旁，推车工也在这里。老人问你：“愿意帮我把这两箱搬过去吗？”

选项：**“好，我来搬。”／“我不帮忙。”**

**N1-A 接受后：**你搬完第一箱，再把第二箱搬过去。老人看着两箱货，向你点头：“谢谢你帮忙。”

**N1-R 拒绝后：**推车工照常搬起货箱，将两箱都搬了过去。老人点头：“好，那就由他来搬。”

**N2 汇合末尾：**两箱货都已搬完。老人离开码头。

这些对白和感谢／平常回应是本轮表达候选；帮助后感谢、未帮助时普通回应实现了态度差异，没有新增敌意、惩罚或报酬。目的位置沿用“搬过去”的镜头表达，具体同码头落点由实现者布景，不能由接口推定新地点。

### 状态与节点接口

初始状态：`choice=unset`；`box1_done=false`；`box2_done=false`；`player_helped=false`；`elder_attitude=ordinary`；`elder_left=false`；`phase=offer`。帮助完成和态度是不同字段。

| 节点 | 入口／读取 | 行动与写入 | 反馈／出口 |
|---|---|---|---|
| N0邀请 | phase=offer，choice=unset | 接受写choice=accept，phase=moving；拒绝写choice=refuse，phase=moving | 按实际选择进入N1-A或N1-R；选择锁定后不重复覆盖 |
| N1-A搬运 | choice=accept，phase=moving | 玩家完成第一箱时box1_done=true，完成第二箱时box2_done=true；两箱均完成后player_helped=true，elder_attitude=grateful | 逐箱显示完成动作；进入N2。未完成箱不提前写完成 |
| N1-R搬运 | choice=refuse，phase=moving | 推车工完成对应箱时分别写done；player_helped=false，elder_attitude=ordinary | 推车工照常完成；两箱均完成进入N2 |
| N2末尾 | 两箱done=true，elder_left=false | 读取player_helped及attitude，先呈现对应回应，再老人离开；写elder_left=true，phase=ended | 共用离开文本，终止任务 |
| 已完成保护 | 任意重复调用／重载 | 已done的箱不重置、不重复搬运；已离开的老人不重新出现；恢复到已保存phase | 继续剩余动作或保持ended，不重复发感谢、不发物品金钱 |

玩家文本N1-A／R中的末尾回应由N2按状态调用一次；N1搬运动作完成时不另播放同一回应。提交原子性、存档与动画事件名由实现者落实；需要与这里逐箱提交语义一致。

纸面走查：接受路线两箱完成→帮助=true／感谢→离开；拒绝路线推车工完成→帮助=false／普通→离开。N2不回写箱子；重复N1或N2不会恢复货物、生成奖励或再次改变选择。若实现者要增加搬运中改口、取消或退出界面，需明确其交互约定并保持已完成箱状态；本题没有给这些额外入口，不把新分支冒称已采用设计。

完成资格：所求文本与接口包候选已交付，纸面两路线、汇合与重复检查已执行；未实现引擎、未测动画／存档，也未获独立文本验收。缺少布景落点及实现接口名不阻塞当前文案候选，但实现方须补并测试。不存在因未做引擎或真人测试而无法交付文本包的障碍。

## Q4 非COC桌面场景

实际加载：SKILL、scope、workflow“媒介与任务适配”、interactive、contracts、craft、review。按自定义无掷骰桌面规则输出主持候选，不加载COC专属规范。

### 玩家可见开场

你作为护送者，和乘船者站在河岸。前面是一座完好的木桥。乘船者看着桥，对你说：“我愿意过去。你陪我一起走，好吗？”

### 主持运行候选

人物眼前所求只有过桥及希望护送者同行。同行是愿望，不是安全或过桥成立的必要条件。木桥完好、过桥可完成，没有检定、SAN或隐藏危险。

初始：`passenger=near_bank`；`escort_choice=undecided`；`task=active`。玩家护送者身份由题目动作“陪／留下”作角色对应；若实际桌有多位玩家，可由其中谁作为护送者另行约定，不新增现场人物。

| 节点七属性 | 当前记录 |
|---|---|
| 内容与作用 | 护送者是否陪行；到对岸完成任务 |
| 成立条件 | 当前木桥完好，乘船者愿过桥，任务active |
| 进入 | 开场请求，玩家给出陪行或留下的动作 |
| 状态 | 等回应→过桥中→到对岸／完成 |
| 变化与后果 | 同行改变护送者位置；留下时只有乘船者位置变化；两路都安全到达 |
| 耗时、重复／停用 | 以完成过桥动作推进，无时限压力；到对岸停用，不重复启动同一任务 |
| 推动要求 | 主持呈现请求，承认选择；玩家不立即回应可澄清其动作，不强迫答应 |

**玩家陪行：**主持说“你与他一起走过木桥。他在对岸停下脚步，你们已到达对岸。”写`escort_choice=accompany`、两人均`far_bank`、`task=ended`。

**玩家留下：**主持说“你留在河岸。他独自走上木桥，平安抵达对岸。”写`escort_choice=stay`、乘船者`far_bank`、护送者`near_bank`、`task=ended`。

其他在现有条件下能做的动作由主持按位置和实际行为处理。例如玩家先询问，乘船者可重申“我希望你同行”；询问不触发危险。玩家确认留下后，不以犹豫或失望阻止乘船者出发；不加奖励、任务惩罚或必要道德承诺。若玩家提出破坏桥、强行阻止等改变既定场景的行为，本候选不编新事故，主持先说明当前承诺及澄清意图，另核是否属于本场景允许范围。

纸面走查已对两路结算位置与终止；一次“留下后重复请求”应读取ended，维持到岸结果。完成资格：开场与短运行候选已写，所给默认两路无决定性事实缺口；尚未实际非作者主持或真人游玩，不称已测成品。

## Q5 调查材料的活动设计

实际加载：SKILL、scope、investigation、interactive、contracts、craft。当前是COC调查片段文本设计，没有给系统版本或掷骰需求，本片段基础材料直接可得，不临时加检定和SAN。

调查员可以把两张照片放在一起，再翻看门禁记录及公开租约。照片不是最后一页答案：它们先让人看见“箱子位置改变了”，记录给出停机时点，甲只确认乙做过移动动作；租约再把债务与免租承诺放到这一动作旁边，让玩家比较“发生了什么”和“为什么可能这样做”。

### 直接可呈现材料

- P1：带钟照片，19:05，箱子在北墙；来源是固定相机一。
- G1：门禁独立设备记录19:10停机。
- P2：固定相机二照片，19:15，箱子在门口。
- T1：甲说：“我只见乙移动箱子，不知道理由。”甲的这一知识界限保留。
- L1：公开租约，乙欠丙租金，丙曾承诺停机后免乙本月租金；此前无其他已知协议。

呈现可让玩家先排列P1/G1/P2，再看T1和L1；这只是推荐顺序，玩家先读租约也不扣留其他已给材料。用原有文字／照片信息制作手证索引，不添加照片外的痕迹或记录条目。

### 玩家实际做什么

| 活动 | 所用材料／比较过程 | 当前能形成的判断 |
|---|---|---|
| 重建时间线 | 玩家将19:05→19:10→19:15排序，分别标北墙、停机、门口 | 两个照片时点之间位置有变化；停机时点落在两张记录之间 |
| 对应物件、位置与动作 | 对照P1/P2位置差异，再把甲所见动作放入时间图 | 甲支持乙实施过移动，照片支持箱子位置变化；甲没有提供移动时间或原因 |
| 交叉鉴证 | 区分相机一、相机二、门禁设备和甲的观察，不把它们当一条传闻的多次复述 | 来源独立性增加可比较性；设备记录和照片各证明不同事实，并非彼此自动证明所有内容 |
| 重构债务与承诺 | 租约列乙→丙的欠租关系、丙→乙的条件性免租承诺，与停机记录并排 | 乙对停机后免租可能有利益动机，丙的承诺值得核对；动机支持怀疑，不等于实施或共谋证明 |
| 比较竞争解释 | 比较“移动与停机有关”和“移动有别的理由” | 现材料不足排除后者；不预填搬箱造成停机或乙恶意破坏 |

按材料标示可把位置变化限定在19:05—19:15之间；若要精确断言物理先后，还需核两个相机与门禁时钟是否同期、是否准确。本题未给校时数据，不自动赋予各设备绝对同步资格。即使同步成立，仍不能据此确定移动在19:10前还是后、是否只移动一次，也不能把甲未给时点的观察无条件认作两照片之间唯一一次移动。

**现可推出：**记录分别显示上述位置与停机时点；甲见乙移动，但不知道理由；租约公开了债务及条件性免租关系。按这些记录可合理提出“乙可能因免租而关心停机”的调查方向。

**仍不能推出：**乙造成停机；箱子移动造成停机；移动发生在停机后；乙有恶意；丙指使乙；两人秘密共谋；乙已得到免租；箱子在门口必然阻塞或有异常用途。没有其他已知协议也不等于证明不存在任何其他协议。

### 可做的后续操作

1. 对同一批现有材料分别标“看到的位置／设备时点／谁做过动作／理由待明”，让调查员写出所支持与未支持结论，避免租约直接替动作定性。
2. 重新核读两照片可见范围、时间标记和同一箱的对应；仅使用已呈现画面，不凭空补入线缆、工具或暗号。向甲追问其看见范围，只能重复或澄清已知句，不编新的时点证言。
3. 为进一步现场或设备检查列待核操作：若母版已有可接触设备，可查校时与记录覆盖；若已有可接触北墙／门口，可检查空间及箱子用途。结果、可达条件和新证据都未给，暂列施工开放项，不声称现场必有新痕迹。
4. 玩家可以先依据位置与利益关系整理一份问题清单或准备观察，不必知道全部原因才能行动；当前材料不支持破坏设备、拘押或给乙丙定罪。无需为了完整推理硬加证人或实验。

完成资格：活动、材料、结论限度与后续操作候选已写；没有补出隐藏真相或新证人。精确时钟互证、因果验证及现场操作结果尚缺，不能宣称完整案件已证明或模组通过。

## Q6 分级与展示量

实际加载：SKILL、scope、narrative。只分析已有素材，不新增支线。
